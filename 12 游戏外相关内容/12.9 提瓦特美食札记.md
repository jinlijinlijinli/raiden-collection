▍<strong>前言</strong>

将军喜欢吃什么我不清楚，但是影喜欢吃甜点这点我还是知道的。

所以虽然神子已经给了我一些三彩团子等点心，但毕竟不是我亲手做的，这不符合我的价值观！这是神子给她的生日礼物，而不是我给她的。

<br/>

所以我想了又想，突然想起来了容彩祭时看到的那本小说…里提到的紫苑云霓…虽然那个只是捏造的情节，也不知道她是不是真的喜欢吃，不过也算是甜点了，应该不至于踩雷才对。

不过只有甜点的话，会不会有种少了点什么的感觉？

<br/>

想起来之前在乌有亭吃过的一道黄油蟹蟹，不知为何，觉得应该是影会喜欢吃的味道，那就这么擅自决定了吧。

<div class="cs-list-miko">对了~我刚才提醒的注意事项都记住了吧？可别惹我的神明不高兴哦。</div>

黄油蟹蟹

首先用刀把帝王蟹腿剁下来；

<br/>

<div class="cs-list-ei">仅仅作为一介武者，这个或许我能帮到你。</div>

<br/>

取50克黄油，在锅里融化后加入大葱煸香，捞出大葱，留葱香黄油备用。

<br/>

烧锅水，加点盐，前面煸香的大葱丢下去，烧开后放入蟹腿烫40秒后立即捞出；

这时候的蟹肉只有靠近壳那一部分是熟的；

这一步是为了让蟹腿表面和蟹壳分开，不然去壳的时候会粘在一起。


<br/>

用剪刀剪开蟹腿上面的一层蟹壳；

<br/>

露出的蟹肉上刷满葱香黄油，不需要额外再加盐了。

<br/>

烤箱预热200度，进烤箱上下火烤制6分钟。

<br/>


取出后再在蟹腿顶部放上50克黄油，余热会让黄油缓慢融化。


<br/>

<div class="cs-list-ei">嗯…看起来好像不是特别复杂，不过不知为何，我就是不会做…</div>

<div class="cs-list-ei">幸好有你，我也能饱一饱口福了。</div>

<br/>
嗯，你先尝尝，还合胃口吗？

<br/>

烤制而成的蟹肉料理。

一口下去，黄油浸润的蟹腿，蟹肉本身的清甜带着馥郁的香气，席卷味蕾，叫人无法抵抗这般鲜香的诱惑。

恍惚间已经吃完了蟹肉，却想再抿一抿蟹壳上的黄油，来回味上一刻的美好。

---

紫苑云霓

那么接下来，就是你最期待的制作甜点环节了。


<br/>


莲蓉加炼乳搅拌成莲香牛奶。

<br/>



淡奶油打发，取出约20克装入小裱花袋，其余加入香芋粉继续搅拌；

搅拌均匀后加入葡萄汁增加果香和减少奶油的稠度，搅匀；


<br/>




杯底加入冰块和莲香牛奶；


<br/>



加入打好的香芋葡萄淡奶油，最上面用打发的淡奶油画出井字；

加薄荷叶装饰；

<br/>


完成。

<br/>

<div class="cs-list-ei">真是神奇，无论是卖相还是香味都能引起食欲。</div>

<br/>


确实是别具一格的饮品。

蒙德生长的嘟嘟莲搅拌的莲蓉垫底，稻妻特产的堇瓜和葡萄封顶，跨越了山海碰撞于一处，柔滑的牛奶与清新的瓜果香气交织相融，带给人耳目一新的享受。

难怪书中的将军大人喝完后也会打起精神，简直毫不夸张。

旅行者 : 绫人？你是来买衣服么？

神里绫人 : 旅行者，真是巧遇。之前我在小仓屋预约了一批布料，按照惯例原本是要送到神里屋敷进行挑选的。

神里绫人 : 只是今日恰好来天守阁与将军大人会谈，所以干脆顺路提前过来看看。

旅行者 : 绫人原来会亲自来挑布… / 我还以为会让府内人代劳。

神里绫人 : 如果只是寻常用布，那自然是有专人安排。

神里绫人 : 但如果是出席正式场合所用的衣物，便要从布料与着色开始考虑，我一般还是会亲自挑选。

神里绫人 : 毕竟…神里家为社奉行，负责文化与民生，一举一动也皆会进入稻妻民众的眼中。购入的布匹样式，自然也瞒不过大家。

神里绫人 : 每一年采买布匹后，都会有不少商家打着「社奉行曾用此布」的名号来推销布匹。

神里绫人 : 之前有一年我曾差使家仆采买，但…却有人拿着摩拉去向他贿赂，呵呵，他倒也不推辞…处理这件事时，也算是颇费了一些功夫。

神里绫人 : 所以，之后涉及到这类事务时，都是由我来亲自处理，也算是提前免去一些麻烦事。

## <font style="color:#967c68;">逸闻纪事·钟离</font>

### <font style="color:#967c68;">钟离·书</font>

>在万文集舍的摊位旁，你遇见了若有所思的钟离。据他所说，是受「往生堂」堂主胡桃所托，前来购买几本「轻小说」。在稍微翻看了几本后，钟离也似乎对这种小说产生了兴趣…

钟离 : 这应该是堂主要的那本…

旅行者 : 钟离，你在看什么呢？

钟离 : 旅行者，幸会。我是受堂主的托付，出来帮她买几本书。

旅行者 : 《拜托了我的狐仙宫司》… / 《转生成为雷电将军…》… / 《异邦人喧哗旅…》…

钟离 : 这只是一部分，还有一些尚未摆在这里贩卖的，我已经托店主去购置了。

旅行者 : 钟离，你看了这些书么？

钟离 : 之前没读过，在堂主的催促下，最近才拜读了好几本。读完之后，倒也觉得有几分趣味。

钟离 : 稻妻的话本，果然与璃月的文风大相径庭。唔…但人各有所爱，倒也分不得高下贵贱。

旅行者 : 不是不是，我的意思是… / 那个，转生为雷电将军…

钟离 : 怎么了？这书里对雷电将军的武艺描绘十分生动。

钟离 : 特别是书中人物对「无想的一刀」的探讨追寻，也很有趣…

钟离 : 唔，天色不早了。旅行者，我还要把书送去给堂主，我们就此别过，回头再见吧。


## <font style="color:#967c68;">逸闻纪事·托马</font>

久岐忍 : 据托马先生说，只要能完整参与一期课程并且通过考试，社奉行就会发放执照，对找工作很有好处。

托马 : 哈哈，有一次收到她的信，一定要我寄稻妻的酒回去，让她尝尝我在稻妻能喝到什么。

托马 : 哪有酒能和蒙德的蒲公英酒比嘛，可惜，她现在要喝家乡的酒就没那么容易了。

## <font style="color:#967c68;">逸闻纪事·绮良良</font>

### <font style="color:#967c68;">绮良良·冰丝丝</font>

## <font style="color:#967c68;">逸闻纪事·鹿野院平藏</font>

### <font style="color:#967c68;">鹿野院平藏·怪案</font>

>在花见坂，你遇见了正在因为一桩「怪案」而苦恼的鹿野院平藏。据他说，犯罪者私自闯入居民家中，但却什么也没有偷。而且，所有被入室的民宅里都有一个共同点，那就是收藏着一本罪案小说 : 《应避忌的食人树》。以此为线索，鹿野院平藏有了一个初步的推理。以他的推理为基础，天领奉行已经外出巡查，准备去缉拿这位奇怪的罪犯。

鹿野院平藏 : 结合其他的调查结果来看…嗯，看来确实可以和之前的几起入室案并案侦查呢。

鹿野院平藏 : 但是，为什么会有犯人入了室，却什么都不偷呢？而且，犯人到底是从哪里进屋的…

旅行者 : 有什么案件发生吗？

鹿野院平藏 : 哦呀，是旅行者，你来得正好，这里有一桩有趣的案件。

鹿野院平藏 : 有一位犯人频繁在城里入室…但犯人在入室后，什么都没偷，只是把书柜什么的翻个乱七八糟，搞得各位居民苦不堪言。

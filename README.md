# raiden-collection

## 简介

欢迎来到雷电将军文本收录资料库！本项目旨在收录《原神》中与雷电将军相关的全面资料，包括剧情片段、人物设定、技能描述以及相关背景故事等内容。同时，也整理了与稻妻地区的人文历史、风土文化相关的内容，以便玩家能够更全面地了解雷电将军这一强大且极具魅力的角色及其所在的世界。

本项目由我亲自整理，同时参考了另一位热心收集者 `ruixiongzhe` 的资料整理工作。特别感谢他提供的详尽内容，大家可以通过以下链接访问完整文本收录：[NGA](https://bbs.nga.cn/read.php?tid=33480880&rand=105) | [Notion](https://raidenshogunlore.notion.site/3a848093829c45d58d899149df67bd3d)

此外，也衷心感谢 [NGA雷电中心楼](https://bbs.nga.cn/read.php?tid=27733026) 的贡献与分享，使本项目能够顺利完成。

希望本资料库能够为大家提供便捷的参考与阅读体验，同时带来更多乐趣与收获。

Welcome to the Raiden Shogun Text Collection Archive! This project aims to compile comprehensive materials related to the Raiden Shogun in Genshin Impact, including story segments, character settings, skill descriptions, and related background lore. Additionally, it also organizes content related to the human history, customs, and culture of Inazuma, allowing players to gain a deeper understanding of this powerful and charismatic character and the world she inhabits.

This project has been personally compiled by me, with reference to the materials organized by another dedicated collector, `ruixiongzhe`. Special thanks to him for providing such detailed content. You can access the complete text collection via the following links: [NGA](https://bbs.nga.cn/read.php?tid=33480880&rand=105) | [Notion](https://raidenshogunlore.notion.site/3a848093829c45d58d899149df67bd3d)

Furthermore, I would also like to sincerely thank the [NGA Raiden Central Hub](https://bbs.nga.cn/read.php?tid=27733026) for their contributions and sharing, which made this project possible.

I hope this archive provides everyone with a convenient reference and reading experience, while also bringing more fun and insights.

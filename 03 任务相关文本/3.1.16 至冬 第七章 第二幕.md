## <font style="color:#967c68;">槲寄生</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">与「丑角」对话，进一步了解情报</font>**

旅行者 : 关于至冬女皇…

「丑角」 : 女皇陛下亲自前往征讨魔物，若非如此，我想女皇陛下应该会很乐意接见你。

旅行者 : （看来至冬并不打算计较我与愚人众过往的那些冲突…）

「丑角」 : 执行官在回收神之心的相关事务上享有自主权，但与之相对，他们也并不会完全代表至冬官方立场。

旅行者 : 我在想的事被你看穿了。

派蒙 : 这么说的话，我有一个一直一直想问的问题，至冬女皇到底是为什么要收集神之心呀，也是为了对抗「天理」吗？

「丑角」 : 毋庸置疑，神之心是对抗「天理」的关键筹码，除此之外…你最好自己去问女皇，我不确定这是否是我应当提供的信息。

派蒙 : 你官这么大，还不确定呀…算了算了。

旅行者 : 对付「天理」这种事，在常人看来就像痴人说梦一样。女皇为何如此执着于这件事？

「丑角」 : 在如今的提瓦特，「文明」不过是虚幻的表象，是随时可以被「否定」的事物。

「丑角」 : 我们的文明可以在抗争中毁灭，但决不能因为「天理」的一个念头便被彻底否定存在，接受消失的命运。

「丑角」 : 唯有改变这种状况，唯有推翻「天理」，我们的文明才称得上是扎下了根基…

「丑角」 : 否则像坎瑞亚、亥珀波瑞亚等国度的人们所经历的，只会不断上演。

派蒙 : 可以「毁灭」…但不能被「否定」…

「丑角」 : 另外…或许对你们来说还有些难以理解。你们是否知道，这个世界的一切规则，都是由「诅咒」所构成的？

派蒙 : 欸？全部吗？我知道你们说的「死之诅咒」，还有你和戴因斯雷布所中的「不死诅咒」…

旅行者 : 丘丘人的诞生…以及纳塔的「还魂诗」规则也是诅咒？我还知道芙宁娜的长寿也源自芙卡洛斯对她的诅咒…

「丑角」 : 嗯，还有…「魔神对人类的爱」，也是天理施加给魔神的诅咒。

派蒙 : 连、连这个都是？

「丑角」 : 女皇一直都有着充分的理由憎恨「天理」…

「丑角」 : 如果女皇能够夺取「天理」的权能，她将会重构整个世界…到那时，人们将彻底从诅咒与谎言之中解脱。

「丑角」 : 请期待吧，那将是超乎你们想象的世界。

「丑角」 : 尽管至冬的普通民众不懂这些，但在这无时无刻不在与环境抗争的雪国，在这从来不被神明所偏爱的国度…

「丑角」 : 我们都相信团结在女皇身边一起「抗争」，定会迎来更好的新世界。

## <font style="color:#967c68;">恢复如初，银瓶裹藏的故事</font>

珊瑚宫心海 : 嗯，它是从前供奉在曚云神社中的礼器，用名为「蜃气楼」的妖怪遗蜕制作而成，能听取往来祈祷者的愿望，蓄积蜃气。

珊瑚宫心海 : 数百年前，此物随最后一代八酝守征战未归遗失在外…

珊瑚宫心海 : 与之相配的宝珠本应能感应到「玉匣」所在，谁料「玉匣」被藏进了「蜃境核心」中，宝珠也就此褪去了光芒。

可莉 : 欸？这是为什么呀？

伊迪娅 : 那我也明白了！蜃境的核心近来老化了…所以「军师」小姐才会捧着宝珠一路走进来。

旅行者 : （听着像我会用的寻宝罗盘…）

珊瑚宫心海 : 但在这片蜃境之内，无数人留下了自己的愿望和礼物，成为了它的「供物」。


## <font style="color:#967c68;">负罪求赎者所遗</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">在「琉形蜃境」前往调查点</font>**

负罪求赎者所遗

_<font style="color:#967c68;">> </font><font style="color:#967c68;">从「琉形蜃境」中寻找到的一张信纸，折叠整齐，折痕处泛黄，看的出来是很久以前有人遗留在蜃境之中的物件。</font>_

【一张折叠整齐的信纸，折痕处泛黄，纸张相当脆弱，其上写着如下内容——】

…时至今日，我仍受困于那场噩梦之中，眼前的一切都仿佛回到了，回到了那片战场，火光焚照天际，如影扭曲的魔物，支离破碎的已看不出形状的躯体，哀嚎在自喉中淌出之前就落入了无声的黑暗。还有…啊，还有将我从漆黑犬兽獠牙之下救出的友人，在战场上，弓刀自他失力的手中落下，身躯逐渐沉入污秽的泥沼之中，半张着嘴的脸朝向我，朝向我…

…我曾侥幸从那场战斗中生还，不，有什么好侥幸呢，是我失去了信心，放弃了手中的十文字枪，丢下了共同对抗灾厄大敌的士卒，如丧神智般逃离了战场。此番作为，愧对将军大人的信任，亦辜负先祖流传至今的声名…事到如今已没有脸面回到八酝。我逃离了战场，但我真的逃离了吗，至那之后，我每日都会梦见凄惨的战场，那些失血泛白的面孔，梦见友人隐入漆黑泥淖前如游丝般呼唤我的名字…往往，只能依靠「蜃楼玉匣」中蜃气所构虚影，才可求得片刻安宁。

…真是可笑，这「蜃楼玉匣」还是作为八酝守受召远讨之前，母亲自曚云神社请来，本想减免我在战场上所受伤痛。那时我还说，「我承袭『喜多院』之名，怎会因区区伤痛使用此物。」想起此事让人汗颜无地。若是让曾为巫女的母亲看到现在这副模样…

…我已经受够了在外流亡，备受折磨的日子了。今日我，今日我终于能够回到此处，啊，我在无数次噩梦中梦见，唯恐避之不及，却又是我无比期冀能返回之处。啊…我的双臂已无法像年轻时那样挥枪自如，但这一次，我一定能挽救我的友人，定能…清除污秽，这一次我一定会跟随将军大人…直到，直到最后一刻。

——喜多院秀家

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与伊迪娅对话</font>**

派蒙 : 总之，事情是这样的！我们在乐园里捡到了这样一张信纸！

派蒙 : 伊迪娅肯定知道这是怎么来的吧。

伊迪娅 : 那是当然，这封信一看就是…咦，这是第一次看到这样的信…

派蒙 : 手掌上的水纹看起来很模糊的样子呢…

伊迪娅 : 这、这显然是趁我不注意的时候，有人悄悄埋下的，第一次看到也很正常的。

伊迪娅 : 而且，从内容上看，比起一封信，更像是留下的遗书和记录，到底是谁呢，信上这个说话的语调，总感觉有点熟悉…

旅行者 : 看上去和「蜃楼玉匣」有关？

伊迪娅 : 啊！这么一说我想起来了，这是把「蜃楼玉匣」带进来的那个老人留下来的…那还是，那还是我来瓶子里没有多久的事。

伊迪娅 : 老人是位稻妻人，一进来就问，这里是不是能够达成别人愿望的秘境，让我把他送回从前的战场…

伊迪娅 : 我设法向他解释，但是…他进入秘境的时候身体状况十分糟糕，看得出来由于长途跋涉，精神也到了有些油尽灯枯的程度…

伊迪娅 : 一个劲地说着「求你了，把我送回那一天…」或者「把我送回那场战争中吧…」这种话。

伊迪娅 : 所以我就用瓶中的蜃境…仿造了他想象中的战场。

派蒙 : 啊，所以信里的「终于回到此处」…

伊迪娅 : 大概是恍惚间醒来，发现周围的蜃境与化作记忆中战场类似的样子了吧。战场还挺可怕的，但，是他却笑得很开心。

伊迪娅 : 怎么会有人在生命的最后想看到那样可怕的场景呢…

旅行者 : 或许对他有别样的意义… / 或许这样比较刺激吧。

伊迪娅 : 这我就不是很懂啦，不过他最后看上去也挺满足的。

伊迪娅 : 如果有一定要在那种场景里达成的愿望，背负那个愿望的岁月里，肯定也很辛苦吧。

伊迪娅 : 在让核心轮縠重新转起来的时候「屋楼玉匣」也帮了不少忙，这么一说，还得谢谢这位秀家先生呢。

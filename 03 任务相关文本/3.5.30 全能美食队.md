旅行者 : 我只是路过。

旭东 : 这样吗？好吧…不过，如果你有兴趣的话，倒是也可以琢磨琢磨这个「屏障」。

旭东 : 芭尔瓦涅从她的那本书里找到过一种方法。

芭尔瓦涅 : 我都说了！这不是什么字典，是教令院的游记简编！

旭东 : 呃，不管是什么，总之她之前找到了一个方法。

旅行者 : 你刚才说的方法…

旭东 : 咦？你是真的想进去吗？

## <font style="color:#967c68;">全能美食队·海滩的横行者</font>

> 在稻妻的海滩上，你又遇见了「全能美食队」…

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与「全能美食队」交谈</font>**

旅行者 : 特别的螃蟹？

旭东 : 没错，就是盘踞在那棵雷樱树下的螃蟹！

芭尔瓦涅 : 你不如直接说…被雷劈过的螃蟹…

旭东 : 哈哈哈，总之我很好奇啦，生活在这种环境下的螃蟹…吃起来会是什么口感。

旭东 : 不过…因为那棵雷樱树旁边落雷不断，我们也不敢靠近…

芭尔瓦涅 : 我的那本书上说…和之前一样，要先去触摸一下「雷樱枝条」，让一种叫做「雷种子」的东西附着在你身上…

芭尔瓦涅 : 这样的话，你就不会被雷樱树旁边的落雷劈到…

芭尔瓦涅 : 但那棵树旁边落雷的声势你也看见了，就凭这么粗略的记录，我可不敢去尝试…

旭东 : 但只要跑得够快，应该就没问题了吧？

芭尔瓦涅 : 我说你啊…你跑得再快，能有雷落下来的速度快吗？！

芭尔瓦涅 : 要我说，我们干脆直接在旁边挖一条沟渠，把水和螃蟹一起引出来好了。

旭东 : 哈哈哈…大家都在各抒己见，不错不错。

旭东 : 旅行者，如果你愿意的话，也去试试抓一下那棵雷樱树旁的螃蟹吧。

旭东 : 如果抓到的话，就拿来给我，我会做一顿大餐好好感谢你的。

旭东 : 哦对了，稍等一下…这些诱饵你拿好。

旭东 : 如果你要去那边抓螃蟹的话，就先用这些诱饵来吸引它们吧。

旭东 : 这样的话，你抓螃蟹的时候应该也会省事一些。

旭东 : 在雷樱树旁生活的螃蟹…唔，不知道味道到底如何…


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">在雷樱树旁放置诱饵</font>**

_<font style="color:#967c68;">> </font><font style="color:#967c68;">在稻妻的海滩上，你又遇见了「全能美食队」。这回他们似乎是想要捕捉一些生活在雷樱树旁的螃蟹。你接受了他们的委托，准备去雷樱树旁捕捉一些螃蟹…如果在捕捉螃蟹时不慎让其逃走的话，可以再在旁边仔细搜寻其他螃蟹的踪迹…</font>_

芭尔瓦涅 : 我的那本书上说，只要去触摸一下「雷樱枝条」，就不会被雷樱树旁边的落雷劈到…

芭尔瓦涅 : 但那棵树旁边落雷的声势你也看见了，就凭这么粗略的记录，我可不敢去尝试…

芭尔瓦涅 : 雷种子怎么有这么多用途呢…真是奇怪…

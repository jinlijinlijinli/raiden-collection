**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与玛达赫对话</font>**

玛达赫 : 旅行者，我从冒险家协会那边听说过，您是在到处旅行，对吧？

玛达赫 : 能不能请您和我说说，您在世界各地的见闻？

玛达赫 : 这样的话，我也能修正一下我搜集来的这些故事，不至于讲得太离谱…

玛达赫 : 当然！我讲故事拿到的报酬，也会分给您一份！

旅行者 : 这倒是没问题…

玛达赫 : 那就拜托您了！您准备讲哪段见闻？

旅行者 : 以前在稻妻…

玛达赫 : 嗯？雷神庇佑的稻妻吗…我听商队的人说，那里有人忤逆了神明颁布的「眼狩令」，应该会是个不错的题材。

玛达赫 : 但从商队那边能打听到的，都是一些断断续续，听起来还不太靠谱的传言…

玛达赫 : 比如说，「一位异乡人向愚人众执行官发起决斗，一刀就将对手化为灰烬！」什么的。

旅行者 : 确实是赢下了决斗… / 降下制裁的是将军啦。

玛达赫 : 唔，再比如说，「他/她直面将军的威压，毫发无伤地从『无想的一刀』下逃出生天！」

旅行者 : 确实是从刀下逃生了… / 挡下那一刀的是别人。

玛达赫 : 欸！那这条呢？「最后他/她从千手百眼神像中汲取力量，扭转了神明的意志…」

旅行者 : 确实改变了将军的心意… / 制胜关键是大家的「愿望」。


`分支一`

玛达赫 : 原来如此…虽然没有传言说得那么厉害，但是「真实感」却明显提高了一个层次啊。

玛达赫 : 简直就像是在向事件的亲历者取材一样，这下传闻里逻辑不通的地方也都能理顺了…

`分支二`

玛达赫 : 原来如此…这些传言，居然大多都是真的吗？现实果然比故事还要不可思议啊。

玛达赫 : 不过就是因为不可思议，这些传闻才会广为流传吧？看来我还能再加工一下…

(略)

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">等候至次日晚间（19-21点）-前往咖啡馆与玛达赫对话</font>**

玛达赫 : 咳咳，今天要讲的故事发生在遥远的异国。各位请听 : 「异邦人稻妻剑刃谭」！

玛达赫 : …雷鸣响彻远海之外，宿命的旅人将到来。他/她于诸岛如电光穿梭，他/她的义举被天下人诉说。

`分支一`

玛达赫 : …那执行官折戟御前，自食傲慢苦果。旅人的同伴们挺身相救，挡下雷霆之祸！

玛达赫 : …净土高悬万千星光，正是凡人心中梦想。终有地上生灵，能撼天上威光！

乃亚卜 : 嘿！这回的故事可算有点意思了。

伊泽姆 : 嗯…和伙伴一起渡过难关吗，这才是英雄故事该有的样子嘛。

玛达赫 : 今天的故事就到这里，欢迎各位下次再来！

玛达赫 : 嘿！您也来了啊，旅行者。今天的故事感觉怎么样？

旅行者 : 还挺有意思。 / 不错的故事。

玛达赫 : 哈哈，和其他客人的评价一样呢。一个新的时代里，会出现新的英雄、新的故事。

玛达赫 : 多亏了他们，我们这行才能干得长远…哦，当然也得谢谢您，这下我应该能喝杯好点的咖啡了。

`分支二`

玛达赫 : …那魔女恣意跋扈，逃不过败北之命数。那一刀劈山开海，也拦不住旅人的去路！

玛达赫 : …还有那千手百眼的石人巨像，驱之以万千愿望的力量。发出雷鸣般轰隆巨响，将阻于道前的诸敌一拍四散！

乃亚卜 : 这故事…新是新了，怎么感觉处处都讲不通。

伊泽姆 : 最后突然冒出个巨大石像来解围，感觉像是编不下去了…

玛达赫 : 呃…那个…今天的故事就到这里，欢迎各位下次再来！哈哈…

玛达赫 : 唉…您也来了啊，旅行者。今天的故事感觉怎么样？

旅行者 : 故事挺离谱的…

玛达赫 : 嗯…和其他客人的评价一样呢。看来是我修饰过度，反而忘了「真实感」。

玛达赫 : 唉…看来我还得再改改这故事…

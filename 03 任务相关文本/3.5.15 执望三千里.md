> 在八酝岛上叫卖矿物的小男孩长次，似乎怀着某些深沉难言的秘密…

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">和长次对话</font>**

长次 : 外国来的人们，请来看看吧，八酝岛最好的蛇骨晶矿！

长次 : 请您过过眼吧，这种品质的晶石以往是直供幕府的，现在折价卖给你们这样的冒险家，一定能为您炼出削铁如泥的利器！

(略)

长次 : 毕竟矿坑已经停产了嘛，因为打仗，还有…大人们经常说的什么「祟神」在岛上作乱…

长次 : 我家的矿石也是卖一枚少一枚的，所以价格难免会稍微偏高一些。

长次 : 再说，这也算「风险溢价」吧~

派蒙 : 「风险溢价」？是什么意思呀…

旅行者 : 「风险溢价」是什么意思呀…

长次 : 唔…就是，我身为小孩子，却像大人一样赚钱。还要承担被天领奉行发现的风险，这就是「风险溢价」！

(略)

长次 : 我的父母都是矿工，这些矿石就是他们开采的！以往工头叔叔会把大家采到的矿石收集起来上交城里的大人，登记封箱后运去踏鞴砂。

长次 : 不过既然现在打仗了，城里的大人也不会来了…

长次 : 我们就自己卖矿石，自己的摩拉自己赚！

长次 : 您看，成色这么好的晶石以前只能卖给幕府，现在冒险家和旅行者也可以买到了，价格公道，品质无瑕！

长次 : 而且我现在也能像大人一样赚钱了，所以打仗也不算是坏事，您说对吧？

(略)

长次 : 是这样的，因为最近的那些事情，矿井已经封闭了。

长次 : 而且那些晶石太坚硬太重了…我一个人实在采不来。

<br/>


**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">取得长次所说的「财宝」-与长次对质</font>**

长次 : 唔…不瞒你说，我们矿工家庭本就贫困…现在遇到这些事端，更是雪上加霜…

长次 : 我是穷人家的孩子，没见过太大数目的摩拉…

长次 : 给你们的这些，对我来说，已经是珍贵的财宝了…

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">取得长次所说的「财宝」-与长次对质</font>**

旅行者 : 岛上有点冷清…

长次 : 以前岛上很热闹，但自从开始打仗以后，大家都陆陆续续搬走了…矿场也空荡荡的了。

长次 : 大家有的往北走了，有的往南走了，现在还没有回来…岛上少了好多人，冷清了好多。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">将晶化骨髓交付给长次</font>**

长次 : 我想离开这个岛。

长次 : 大家要么走了，要么生病了…八酝岛已经没有几个人了。

长次 : …我不想天天打仗，也不想活在「祟神」的包围中…我想远离这里，离开这座岛。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">前往长次的家</font>**

长次 : 好吧，这是我家制作渡来禽肉用的菜谱，请看一下。

长次 : 这道菜最初是幕府的外国人泽维尔教给我们的。听他说很适合矿工补充能量呢！

长次 : 家里的堇瓜足够了，所以不必交给我，也还有小麦可以磨成面粉。

长次 : 但是既然要做禽肉料理，没有禽肉是不行的，而且还需要鸟蛋作为配菜。

长次 : 虽然都不是什么罕见的食材，不过以现在八酝岛上的条件…既然旅行者有意帮忙，就请找一下这几样吧。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">解决长次的烦恼</font>**

旅行者 : 每天都吃的话… / 会吃腻的吧。

长次 : 如果是妈妈做的，就不会腻。

长次 : ……

长次 : 我努力攒钱就是为了离开八酝岛，吃更多好吃的料理，也给更多人做好吃的料理！

长次 : 听说离岛那边只剩下一条往至冬国去的往返航线还没被关闭…可能我还有机会吧。

长次 : 听大人们说，只要有足够多的摩拉，就连奉行大人本人都会开眼让我们出海的。

(略)

长次 : 岛上开始下雨后的第十天，妈妈就走了。

长次 : 信也好，纸条也好，也没有留下…

长次 : 不知为什么，我很早就感觉她会离开。尤其是矿场的叔叔阿姨们给爸爸立碑的那天…


<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 以前这里是什么样呢…？</font>
        <br/> 
        长次 : 你知道吗，在打仗之前，在幕府的大人关掉矿场之前…我们都过得很好。<br/> 
        长次 : 没有人会吃不饱，没有人会受穷…大家有吃不完的东西，也会送给彼此。房间也好，场地也好，大家都会互相帮忙打扫。<br/> 
        长次 : 叔叔阿姨们大家都一起在矿场干活，平常也互相帮助… 
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 幕府没有干涉这里吗…？</font>
        <br/> 
        长次 : 城里的大人每隔一阵子会来收购矿石，对我们指手画脚的。<br/> 
        长次 :  但我们自己的事情都是我们自己开会解决。城里人有城里人的规矩，大御所大人也给我们安排了自己的规矩…<br/> 
        长次 : 如果不是打仗的话，我再过两年也要参会「旁听」了，但我不太懂那些。 <br/> 
        长次 : 他们说这是什么「义务」…不过我才不喜欢和一群大人挤在一起，太无聊了。<br/> 
        长次 : ……
    </li>
</ul>

长次 : 可是现在大家都不在了。

(略)

长次 : 我会先在八酝岛寻找的。可能会去问问那个叫保本的医生叔叔…可是他好像讨厌我，每次远远看到就躲着我…

长次 : 然后，我可能会去找找爸爸的工友…之前听说梶先生还在岛上，他或许知道关于妈妈的事。

旅行者 : 可是有很多海贼出没。

长次 : 嗯…海贼叔叔那边也可以求助…虽然他们和幕府的大人们合不来，但对我们也还算亲切。

长次 : 他们说不定会同意带我一起出海。

长次 : 再然后…唔，那个人不行，他很可怕。

旅行者 : 谁？

长次 : 绯木村的村长鹫津…他以前是个很好的人，但现在…很奇怪。

长次 : 他很可怕，总是远远地盯着我家自言自语。我总觉得他会对我…或者对我妈妈做坏事。

长次 : 希望妈妈没有遇见过他。

长次 : 啊，说起鹫津…我可不可以再拜托旅行者一件事？

旅行者 : 请说无妨。 / 与那位鹫津有关？

长次 : 嗯，鹫津以前在岛上搭了一些神龛，原本是为了用供奉来安抚大蛇的灵魂…

长次 : 毕竟我们总要直接接触蛇骨晶矿，时间长了难免会生病嘛。

长次 : 但是自从矿场关闭之后，鹫津也越来越不对劲，越来越可怕了…他供奉神龛的方式也越来越…疯狂。

长次 : 再后来，这样评论鹫津的大人也一个一个消失了…

长次 : 话说回来，妈妈以前经常去附近的神龛为爸爸和我祈祷，在那里献上绯樱绣球的花瓣。

长次 : 我想去那边看看她是否有留下什么信息…可是又害怕会遇到鹫津，我不能靠近那边。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">调查神龛</font>**

_<font style="color:#967c68;">> </font><font style="color:#967c68;">长次曾提起他的母亲经常在神龛前祈祷，不如去调查一下。</font>_

神龛 : 这就是长次所说的神龛了吧？

神龛 : （看起来很普通的神龛，并没有任何奇特的元素痕迹。）

神龛 : （这座神龛朴素却优雅，木造的龛体微微闪烁着流光，以端庄的沉默迎接来客的供奉。）

神龛 : （神龛旁边散落着许多神樱花瓣，看起来不像是自然所成，却像是有人特意在这里洒下了绯樱绣球。）

派蒙 : 唔…这里也没有痕迹呢。

旅行者 : 看，绯樱绣球… / 是长次妈妈的供品…

派蒙 : 对哦，长次提到过他妈妈会在神龛供奉这个的！

派蒙 : 这么多花瓣出现在这里…应该不会是偶然。

派蒙 : 我们快回去告诉他吧！


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">和长次对话</font>**

旅行者 : 我们调查了神龛。

派蒙 : 可惜你的妈妈并没有在那里留下什么信息…

长次 : 这样啊…

派蒙 : 但有人在那里留下了很多绯樱绣球的花瓣。

旅行者 : 是她供奉的花。

(略)

旅行者 : 不去找奉行方吗？

长次 : 唔…谢谢，不了。我们不信任城里的人。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">继续和长次对话</font>**

_<font style="color:#967c68;">> </font><font style="color:#967c68;">战争与「祟神」给小小的长次带来了太多烦恼，如何才能让长次走出迷惘呢…？</font>_

旅行者 : 可是幕府垄断了晶矿市场。 / 你知道晶矿不好卖吧？

(略)

长次 : 我收集晶矿也不完全是为了赚钱。

长次 : 我一直在想…假如爸爸妈妈也像大家一样，得了「祟神」带来的病…

长次 : 或许这些晶石能用来制药也不一定。因为它们也是大蛇的骨骸上生出来的嘛…

长次 : 而且保本先生也提到过，这些晶石可能有用。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">交付矿石</font>**

长次 : 接下来我应该会去踏鞴砂，妈妈曾在那里工作过。或许还有人能告诉我她是否经过那边。

长次 : 再然后…我会想办法去鸣神岛。然后搭一艘至冬国的商船…之后的事情，随机应变。

(略)


<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">在鸣神岛与长次对话</font>**

长次 : 旅行者，没想到又能在这里看见你！

派蒙 : 好久不见啦！八酝岛外的世界怎么样？

长次 : 这里比家乡富裕很多，也有更多好吃的料理、好玩的东西。但是…我不太喜欢。

派蒙 : 欸？为什么？

长次 : 这里的人都缺少了些什么…

长次 : 从前在八酝岛生活的时候，大御所大人对我来说遥远安详…我们不会在意她在哪里，但是我们相信她就在这里，注视保护着我们，规定我们怎么过日子，成为什么样的人…

长次 : 但是在这里，大御所大人覆盖一切，威压一切…

长次 : 唉，我也说不清楚啦…

(略)

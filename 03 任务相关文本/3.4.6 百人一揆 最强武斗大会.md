## <font style="color:#967c68;">活动简介</font>

在稻妻城的秘密会馆中，举办着神秘的乱斗大会「百人一揆」。在场馆中华丽地展现武艺，击败对手赢得积分，就有机会斩获挑战的奖励。

## <font style="color:#967c68;">「百人一揆·最强武斗大会」</font>

> 在稻妻城，似乎有人在寻找格外出众的战士…

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与茅葺一庆对话</font>**

茅葺一庆 : 事情是这样的，最近似乎又有人在秘密举办「百人一揆」了。

茅葺一庆 : 过去模仿天狗的「天狗党人」当中，曾经流传过某种传统仪式。简单来说，是这样的——

茅葺一庆 : 时令不景气时、心情低落时；或是有值得庆贺的喜事发生时；或者只是单纯感到无聊的时候…

茅葺一庆 : 就是通过酣畅淋漓的打斗，来进行庆祝、或者消除晦气。

旅行者 : 好像什么时候都能举办…

茅葺一庆 : …仔细一想，似乎确实是这样。

茅葺一庆 : 总之，我们换个地方说话吧。城里人多口杂，不太方便…

茅葺一庆 : 我们到了。

茅葺一庆 : 只要踏入这扇看起来十分可疑的大门，就能进入百人一揆的场馆。

旅行者 : 好兴奋。 / 好可疑。

茅葺一庆 : 虽然「天狗党」早已因为有违公序良俗而被取缔，但不时还会有人秘密举办百人一揆的乱斗大会。

茅葺一庆 : 而来自世界各地渴求争斗的魔物、冒险者、战士，冥冥之中也会被它吸引，在它的舞台上酣畅淋漓地大打出手。

茅葺一庆 : 你可以和志同道合的同伴、战友一起去参战。毕竟，所谓「百人」，自然是人数越多越好啦。

        <br/> 
        茅葺一庆 : 长大了才发现，我实在没那个才能。所以我决定，去写武者的故事。能在字里行间绽放光彩，也算是一种「武道」吧。
        <br/> 
        茅葺一庆 : 虽然当武官的文胆也不失为一种选择，但我还是更想写像你这样洒脱的异邦战士的故事。
        <br/>

## <font style="color:#967c68;">关卡名及介绍</font>

::: info <font style="color:#967c68;">「诵读俳句吧！」</font>
由逐电武人与无宿盗贼组成的团体，似乎也为了追求酣战之快以及传说中的「天狗党人」留下的宝物来到了百人一揆的场馆中！
:::

::: info <font style="color:#967c68;">时雨御免</font>
传说雨是来自星海的回声！下雨的时候，有的人会去避雨，有的人会寻找水丘丘萨满！不要让雨水熄灭酣战的热情之火，向袭来的丘丘人展示战斗的风度吧！
:::

::: info <font style="color:#967c68;">丸丸用心棒</font>
据说百人一揆特殊的规则与可疑的入口都与元素地脉有关…？如果这么解释的话，那在挑战中出现史莱姆的大军似乎也不是什么难以理解的事情了！
:::

::: info <font style="color:#967c68;">丘丘红莲喧哗屋</font>
这场比试的对手似乎是有着特殊习俗的丘丘人部族！不过这种事情在百人一揆的场馆中并没有什么所谓，只需要知道对方也是迷醉于战斗之情热的异族同侪就可以了！
:::

::: info <font style="color:#967c68;">牙牙伊卡挑战状</font>
在丘丘人当中流传着这样的规矩 : 力气够大、打架够狠的，就能成为它们当中的首领。而这附近没有比百人一揆的会馆更好的打架场地了…！
:::

::: info <font style="color:#967c68;">屹立于大地之上</font>
百人一揆的战斗中接连遭遇惨败的丘丘人，随着强大的同伴卷土重来了！遗迹机关，屹立于土俵之上！
:::

冈崎寅卫门 : …现在，只差岩藏光胤的刀了。

柳叶岚士 : 岩藏家祖传的「薄缘满光天目」吗。当初你和久仁彦刚被收养的时候，趁前代的永胤大人不注意…

冈崎寅卫门 : 我们已经「破门」了。不用叫大人了。

柳叶岚士 : 但是，冈崎…

柳叶岚士 : 「将『情』与『义』置于天平两端，真正的剑士只有『义』之道可走。」

柳叶岚士 : 既然师父这么说，那就说明他不情愿将我们逐出师门，但又没有其他的选择。

冈崎寅卫门 : 当然不愿意了。但既然他已经决定成为将军的刀，贯彻眼狩令，那我们也只能…

柳叶岚士 : 我们只能选择我们自己的道义了。毕竟，「真正的剑士只有『义』之途可走。」

柳叶岚士 : 但是，师父的道义，终究也被挫败了。

冈崎寅卫门 : 没错。不止是久仁彦的仇，其他人，还有岩藏光胤的仇，我们都要报。

冈崎寅卫门 : 这就是我们这些破门弟子的道义。

柳叶岚士 : 这也是师父的保佑吧。第一个仇家，就这样送上门来了。

冈崎寅卫门 : 也对。旅行者就是你吧。你的事迹，我已经听说了。

冈崎寅卫门 : 在剑士的世界里，只有用血才可以洗净「血」。面对岩藏流「免许皆传」的准备，你已经准备好了吧！

岩藏光造 : 我究竟是为什么而离开道馆，成为九条大人的指南的呢…

岩藏光造 : 柳叶和冈崎，还有三船…又为什么会离开我呢…

旅行者 : 岩藏流的门生，我已经拜会过了。

岩藏光造 : 是吗。

岩藏光造 : 现在还有人，会以岩藏流的名号自居吗。明明宗主是这么不成器的人。

岩藏光造 : 我是岩藏光造，姑且在这里担任剑道指南。阁下是？

旅行者 : 我是旅行者。

岩藏光造 : 三船、丹波…你见到他们了吗？还有冈崎兄弟。

岩藏光造 : 还有片山。他喜欢在一决胜负之前，给这场比试取名。

岩藏光造 : 因为，「如果将来我成为了真正的剑豪，那这些比试都是可以写成故事的」。哈哈哈，真是瞎胡闹…

岩藏光造 : 对了，还有从「永胤」的时代到「光胤」的时代，都无法突破「初传」的岛田。

岩藏光造 : 他们因为无法领会将军大人「眼狩令」的气量，似乎是落草为寇了。

岩藏光造 : 过去指导他们握刀挥剑的岁月，真是令人怀念。我究竟为什么关闭了道馆，来到了军中呢？

岩藏光造 : 旅行者阁下，他们的本领如何？

旅行者 : 很遗憾… / 多有受教。

岩藏光造 : 是吗…

岩藏光造 : 那么，旅行者阁下，你师承自谁？土门？还是说，是涉川的流派？难道是鸣神亲传？

    </li>

        岩藏光造 : 看来岩藏流，终究还是在我手上没落了。亲自教出来的弟子，在真剑比试中竟然无法胜过不愿自报家门的人。

岩藏光造 : 我姑且是岩藏流不成器的宗主。作为剑客，名号是「岩藏光胤」。

岩藏光造 : 虽然秘剑的心得我已经不记得了，「神之眼」也交给了将军大人…

岩藏光造 : …不过，若是要为那些不甘于我的堕落，而走上忤逆的恶鬼之道，

岩藏光造 : 却又不那么成器、败在了你手下的门生报仇的情义，还是有的。

岩藏光造 : 这里不够开阔，恐怕你的剑技也难以施展吧。跟我下去。

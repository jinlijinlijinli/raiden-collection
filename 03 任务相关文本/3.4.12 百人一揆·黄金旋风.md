## <font style="color:#967c68;">活动简介</font>

在稻妻城附近不为人知的秘密会馆中，似乎举办着无论是渴求争斗的战士，或是单纯好战的魔物都能接纳的乱斗大会·百人一揆。
编制二人一组的搭档队伍，在场馆中华丽地展现武人的名迹，提高争斗的热度吧。

## <font style="color:#967c68;">「百人一揆·黄金旋风」</font>

> 距离上次的「百人一揆」结束已经有一段时间了，而茅葺再次出现在了稻妻城里…

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与茅葺一庆对话</font>**

茅葺一庆 : 嗨！那边那位金发异乡人…

旅行者 : 又见面了。 / 有什么委托吗？

茅葺一庆 : 嗯…你这头金发，越看越眼熟…难道是…

茅葺一庆 : 啊，对了！是上次「百人一揆」中，表现无比亮眼的「黄金旋风」…

旅行者 : 黄、黄金旋风…？

茅葺一庆 : 上次，我在乱斗的场馆一隅，观察着参加者的活跃表现，想将其中最为精彩的场面收为素材。而你战斗的身姿，如刈草的黄金之风一般，横扫各路敌手…

<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 奉承的话就免了。</font>
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : …再多说点？</font>
        <br/>
        茅葺一庆 : 咳咳…「想必观众当中拥有剑豪般动态视力的人已经看出来了，这位金发异人所使用的正是在古武术中也被视为禁忌的『苟兰茄大龙卷』…！」<br/>
        旅行者 : ？<br/>
        茅葺一庆 : 这是受你战斗的身影启发，而写的情节。
    </li>
</ul>

茅葺一庆 : 无论如何，最近又有好事之徒举办「百人一揆」了。

<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 「百人一揆」是什么来着？</font>
        <br/>
        茅葺一庆 : 通过酣畅淋漓的打斗，来进行庆祝、或者消除晦气的乱斗大会。无论是武人还是魔物，都能摈弃成见不问身份，在其中为了纯粹的热血而混战的祭典。<br/>
        茅葺一庆 : 在其中脱颖而出者，据说也能得到各种宝藏。<br/>
        茅葺一庆 : 虽然举办者、赞助者究竟是何许人也，至今都是谜团就是了。
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 原来如此，我明白了。</font>
    </li>
</ul>

茅葺一庆 : 总之，这些事情不适合在人多口杂的地方讨论。跟我来…

茅葺一庆 : 我们到了。

茅葺一庆 : 只要踏入这扇看起来十分可疑的大门，就能进入这回的战斗场馆。

旅行者 : 好兴奋。 / 好麻烦。

茅葺一庆 : 这次的规则和上次应该差不多。来自世界各地，渴求争斗的魔物、冒险者、战士，在它的舞台上酣畅淋漓地大打出手。

茅葺一庆 : 与之前一样，你可以和志同道合的同伴、战友一起去参战。毕竟，所谓「百人」，自然是人数越多越好啦。

茅葺一庆 : 我很期待你的表现。

旅行者 : 这次你也不参加吗？

茅葺一庆 : 我吗？我会以旁观者的身份参与，为你喝彩。

茅葺一庆 : 毕竟，我的目标还是写出最精彩的格斗小说，而不是成为像你这样耀眼的战士。

茅葺一庆 : 而我的直觉告诉我，你一定会是格斗场上最耀眼的明星。

旅行者 : 我会尽力。 / 拭目以待吧。

茅葺一庆 : 嗯。想必这次你也能展现出耀眼无比的剑之舞吧。

<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与茅葺一庆对话</font>**

茅葺一庆 : 嗨，怎么了吗？

<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 关于小说…</font>
        <br/> 
        茅葺一庆 : 我小的时候，也是读着话本、小说长大的，也想着长大了要变成像岩藏之胤、喜多院那样武艺高强，斩妖除魔的武者。
        <br/> 
        茅葺一庆 : 长大了才发现，我实在没那个才能。所以我决定，去写武者的故事。能在字里行间绽放光彩，也算是一种「武道」吧。
        <br/> 
        茅葺一庆 : 虽然当武官的文胆也不失为一种选择，但我还是更想写像你这样洒脱的异邦战士的故事。
        <br/> 
        茅葺一庆 : 你上次在「百人一揆」中的表现，我已经写成了样稿，交给八重堂的编辑审阅了。不知情况如何呢…
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 关于之前…</font>
        <br/> 
        茅葺一庆 : 上次你在「百人一揆」当中的表现，实在是太精彩了。
        <br/> 
        茅葺一庆 : 即使是「心流」的宗主涉川，恐怕也难以想象出这样的武人吧…
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 关于「百人一揆」…</font>
        <br/> 
        茅葺一庆 : 最早是过去的「天狗党人」举办的神秘仪式，旨在宣扬打闹的好处。
        <br/> 
        茅葺一庆 : 但在他们被取缔后，还是会不时有人秘密举办。举办者的身份至今都笼罩在疑云之中。
        <br/> 
        茅葺一庆 : 总之，是相当热闹的乱斗大会。无论什么人、甚至是魔物都能参加。
        <br/> 
        茅葺一庆 : 对于渴求争斗的人来说，再合适不过了。
    </li>
</ul>

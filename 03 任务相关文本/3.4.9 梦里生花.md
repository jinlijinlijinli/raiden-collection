## <font style="color:#967c68;">活动简介</font>

稻妻花匠「咲耶」小姐为了推广自己的「咲耶花屋」，正举办着一场全新的推广活动。


**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与咲耶对话</font>**


咲耶 : 你好！想要试试亲手种一盆花吗？

<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 关于花卉的事…</font>
        <br/> 
       咲耶 : 你是想要体验一下种花和插花的乐趣吗？没问题。
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 关于插花…</font>
        <br/> 
        咲耶 : 「插花」在稻妻可是一项很重要的事情喔。<br/> 
咲耶 : 虽然简单来说，「插花」就是将花卉和其他植物仔细裁剪处理后,以一个合适的方式摆放起来…<br/> 
咲耶 : 但在具体制作上…裁剪花卉和植物时，需要细细地把握植物的状态，细心地为植物修剪掉不体面的地方。<br/> 
咲耶 : 摆放时，又要根据具体的场景氛围来调整摆放的方式。有时候，甚至要细致到每一支花弃向外延伸的角度…<br/> 
咲耶 : 这些细节，每个都需要细心考究，实在是…繁琐到了极点。<br/> 
咲耶 : 就算是对我这个喜爱插花的人来说，这项工作也够让我疲惫的了。
    </li>
</ul>

## <font style="color:#967c68;">地狱: 山中好长日·第二章</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与伊斯托利亚对话</font>**

伊斯托利亚 : 看来我们都被重新投入无想之间了。

旅行者 : 所以我们应该怎么出去？

伊斯托利亚 : 常规办法就是学习冥想，控制心和思绪。然后抛弃所有渴望的念头。

伊斯托利亚 : 保持什么都不想的状态。

伊斯托利亚 : 说着挺简单的。但是根据人的素质和渴望程度之不同，办到这一点从几年到几百年的都有。

伊斯托利亚 : 像你这种背负世界命运的人，渴望恐怕无法被自己割舍吧。何况也不应该被舍弃。

(略)

<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">收集「念亡碎片」</font>**

阿罗逻 : 虽然我不知道你们的时代，但是我叫阿罗逻，本是寂静期行者。

阿罗逻 : 来到这里已经记不得时间了。甚至这里把我的寂静之修行破掉了。

阿罗逻 : 果然，无念无想的修行会让人投生无想恶天啊。

(略)


## <font style="color:#967c68;">审判: 山中好长日·第三章</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与彩特琳德对话</font>**

彩特琳德 : 刚才看到的，其实全都是小时候姐姐给我读过书时，我们幻想过的外面的世界。

彩特琳德 : 枫丹高海之下是否真的有沉船宝藏，稻妻的镇守之森里是不是真的有妖怪？

(略)

<br/>

曾我隅田流左近重衡 : 贵殿，暂请留步。

曾我隅田流左近重衡 : 省去委细之事，某有一事相求。先日，璃月的虞黄衣殿下曾向某寄送一件稀代的珍品，然至今未达…

曾我隅田流左近重衡 : 某怀疑其为此地守护者所掠取。若贵殿见到虞黄衣殿下所说的「珍品」，可否为某取回？届时，某必将奉上相应的报谢。

派蒙 : 我们回来啦！你看看，这个是不是你说的「珍品」？

曾我隅田流左近重衡 : 哦哦，感激不尽，感激不尽！多谢两位相助！

曾我隅田流左近重衡 : 那么，事不宜迟，某这便启封——

曾我隅田流左近重衡 : 这、这是…！

派蒙 : 呜哇！这东西是不是快要炸了？！

曾我隅田流左近重衡 : 虞黄衣殿下不会害某…莫非是被守护者所寻获，改造成了所谓的「爆弹」吗？！

曾我隅田流左近重衡 : 实是耻辱，但某对如何拆解「爆弹」一窍不通…无计可施，只好把它丢出去了！

曾我隅田流左近重衡 : 不必担心！某还记得，有位从「亥珀波瑞亚」来的殿下好像说过，应当如何丢出神圣的「爆弹」！

曾我隅田流左近重衡 : 「汝当数到三，不可多，也不可少；汝既不可数四，也不可数二，五是数多了。当汝数到的数是三——」

派蒙 : 废话太多啦！再不扔就真的要炸啦！

派蒙 : 什么嘛，虚惊一场，搞了半天原来就只是烟花而已…

曾我隅田流左近重衡 : 何、何等绚烂…某追随御建鸣神主尊大御所大人征战时，还从未见过这般夺目的火之花…

曾我隅田流左近重衡 : 原来如此，这便是虞黄衣殿下让某观赏的奇景么…恐悦至极，恐悦至极…

曾我隅田流左近重衡 : 「漆夜如乌玉，夜半云居绽明花，身似水间沫；须臾一刹终归寂，星离雨散落片空…」嗟乎，何等风雅…

派蒙 : 虽然不知道你到底在风雅些什么啦…总之没事就好！

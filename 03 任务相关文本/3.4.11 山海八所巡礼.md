五百藏 : 吾辈本来还以为，人类都跟把吾辈妖狸一族封印的家伙一样，又坏、又可怕。看来，还是有些好人。

旅行者 : 大部分人都是好人。 / 谢谢。

派蒙 : 对呀，我和旅行者遇到的人，大部分都是好人。五百藏被封印还不是因为把梳子偷走了…

五百藏 : 哼，现在梳子已经给你们了。如果你们遇到那个跟灵善坊学法术的家伙，跟他说一声，让他把吾辈从石头里弄出来。

五百藏 : 吾辈在这里坐了这么久，都怪那个臭狐狸…

(略)

五百藏 : 咳咳。之前也说了，你们是好人，所以…

派蒙 : 是请人帮忙的语气耶。

五百藏 : 呶！吾辈好歹是得了大御所大人的令，守护镇守之森的隐神保生司正，如果不是被封在石头里，吾辈一定要用八叠大的…

旅行者 : 有什么需要帮忙的？

旅行者 : 这个嘛…

派蒙 : 嗯嗯，旅行者的意思我懂！有什么宝藏吗？

五百藏 : 宝藏？那当然了，吾辈可是五百五妖狸的统领，稻妻的宝藏，什么没见过。

旅行者 : 那么，有什么需要帮忙的？

派蒙 : 对，我们最会帮忙啦！

五百藏 : 虽然吾辈没办法自由行动，不过孩子们没问题。吾辈想要拜托小辈你们，带小狸子去外面「修行」。

五百藏 : 就带「吉法师」去吧。上次和你们一起玩以后，他就一直念叨着，想要再见到你们。

旅行者 : 可以是可以… / 还有个问题…

派蒙 : 嗯，毕竟我们和吉法师语言不通，一同旅行的话，多少会遇到困难吧？

五百藏 : 怎么可能。吾等妖狸一族，自然是明白人类的语言的。只不过是你们人不明白一般妖狸说的话罢了。

旅行者 : 不过作为旅伴… / 还是希望能一边旅行、一边聊天。

派蒙 : 就像派蒙和旅行者那样！

五百藏 : 呶，真拿你没办法。之前不是有谁用吾等妖狸一族的法术，给你们做了吃食吗？

五百藏 : 别看吾辈现在是这个模样，做出让你们能听懂吉法师说话的「饭」，也不成问题。

(略)

五百藏 : 哼！吾辈可是活了好久好久的妖狸大王隐神五百藏，怎么会像你们人类那样，对时间这么计较呢！

派蒙 : (虽然大部分时间都被封印在石像里啦。)

旅行者 : 不过，为什么五百藏可以和人对话？

五百藏 : 呶，真没礼貌。应该是，为什么你们人类可以和吾辈对话才对。

五百藏 : 像吾辈这样活了好久好久、力量强大的妖狸，多少都和人类打过交道。

五百藏 : 好久好久以前，吾等经常和天狗、狐、鬼、妖怪与人打交道。人的故事虽然总在说人，其实有一半是妖狸伪装成的人类的历史。

五百藏 : 剩下一半的一半是人类自己的故事，另一半是天狗、狐、鬼和其他妖怪的故事。

五百藏 : 不过，这一半里面，也有一半是吾等妖狸伪装成他们的故事。然后，所有妖狸的故事里，有一半是吾辈五百藏的故事。

(略)

五百藏 : 那就好。这个孩子就拜托你们了，带他到外边去修行吧。

五百藏 : 吾辈还是个幼狸的时候，也曾经巡礼稻妻十八所，寻访过去大妖狸「九百九」的名迹，绝不偏离狸道，才能达到今天的高度。

(略)

## <font style="color:#967c68;">大雪隐御伽话</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">去龙脊雪山前和五百藏对话</font>**

五百藏 : 吉法师这孩子就交给你们了。他很有智慧。等他长大了，吾辈打算将妖狸大王的称号与保生司正的责任交给他。

五百藏 : 所以，小辈你一定要照顾好他！不要让吉法师着凉了！

(略)

派蒙 : 白色的…啊，那些是「雪」喔！

「吉法师」 : 「雪」…「樱吹雪」的雪？神樱树？

派蒙 : 不是啦，雪就是龙脊雪山这些很冷很冷的白色东西。

派蒙 : 不过，吉法师竟然知道樱吹雪这样的词，应该说不愧是稻妻的妖狸吗…

(略)

派蒙 : 不过，风景也很不错！既然从影向山上能看到这里，那从山顶上也能看到影向山吧！

(略)

五百藏 : 这是、这是「地狱绘」？怎么会在你的手里？为什么？

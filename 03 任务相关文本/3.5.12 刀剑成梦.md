**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">帮「无名武士」寻找酒-向军士打听酒的事</font>**

`旅行者被通缉`

九条政仁 : 嗯？军营之内，怎么会有你这样的平民闲逛？

旅行者 : 关于「无名武士」…

九条政仁 : 既未追随大名，又不在战场杀敌，你所说的此人，是个浪人吧。

九条政仁 : 我麾下军中，不会有此等人容身之地。

九条政仁 : 你只是来打听人的吗？打听到消息的话，就早点离开吧。

九条政仁 : 近来有贼子潜入城中，伺机袭击了将军大人，我军内也收到了追拿通缉犯的命令。

九条政仁 : 看你模样，也是金发，说不好会被误认成通缉犯，还是早点回家吧。

九条政仁 : 你这瘦弱体格，别说与将军交手之后生还，估计连我的一枪也接不住吧，我可不希望平民受到牵连。

九条政仁 : 不过你确实有些眼熟，你这相貌…

(略)

`旅行者未被通缉`

九条政仁 : 嗯？军营之内，怎么会有你这样的平民闲逛？

旅行者 : 关于「无名武士」…

九条政仁 : 既未追随大名，又不在战场杀敌，你所说的此人，是个浪人吧。

九条政仁 : 我麾下军中，不会有此等人容身之地。

九条政仁 : 况且军营之内，秩序为上，不是平民可以前来肆意走动的地方，请你早点离开。

(略)

<br/>

松平 : 你也看到了，我还在为军队效力，不能随便离开…

旅行者 : 只需要从前的酒就可以。

松平 : 酒…只要酒就可以了吗？

松平 : 我明白了，那就把我随身带着的那壶酒给你们吧。

松平 : 以前，那家伙还在军中的时候，经常和他的同乡，还有我，三人一同饮酒。

松平 : 他和他那个同乡是穷苦人出身，总是受同营那些富家出身的混蛋排挤。

松平 : 他是个粗犷的汉子，那些排挤他全不在意，只知道在战场上拼命。

松平 : 当时的大将欣赏他，提拔他和同乡两人一跃成了旗本。

松平 : 可是没想到后来，那场合战中…

松平 : 唉，一提到过去就想到些让人难受的事，不唠叨了，没意思。

松平 : 酒我已经给你们了，没有其他事就离开吧。

松平 : 这里毕竟是军营，而且最近上头刚下发了通缉令，风头紧的很。

松平 : 你们这些生面孔就不要久留了，免得遭人误会。

(略)

<br/>

石川 : 希望这脆弱的和平能维持得久一点…

旅行者 : 关于「无名武士」…

石川 : 你说的这家伙真是奇怪，我可不认识这种人。

石川 : 不过最近上头发了通缉令，有个大胆狂徒居然敢冲撞将军，那疯劲儿倒是跟你说的这个人有点像。

石川 : 通缉犯的相貌特征…嘿，我怎么给忘了？真是…

石川 : 总之我要是你，肯定离你说的那家伙远远的，万一是通缉犯呢？还是命重要。

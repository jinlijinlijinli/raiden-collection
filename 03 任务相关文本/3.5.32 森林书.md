## <font style="color:#967c68;">林中奇遇</font>

### <font style="color:#967c68;">维摩庄的孩子</font>

派蒙 : 素达蓓，你想听什么样的故事呢？

素达蓓 : 什么样的故事都可以！不过，素达蓓想要故事里有很聪明、很厉害的大姐姐。或者，不是大姐姐也行。但是，要有决心和爱。

素达蓓 : 就像故事里的辛娜梦公主，和老虎一起离开了宫殿！

旅行者 : 要求好多…

派蒙 : 嗯…倒是有这么一些大姐姐，不过都和雷元素有关…

素达蓓 : 雷元素好，能让植物生长得更加茁壮，让果实更加饱满。

派蒙 : 素达蓓懂得真多！故事应该怎么开头呢…

<ul class="colored-list">
    <li>
        <font style="color:#967c68;">旅行者 : 「在遥远的地方，有一个图书馆…」</font>
        <br/> 
        派蒙 : 丽莎小姐的故事也可以啦，不过我想说的是另一个…<br/> 
        派蒙 : 咳咳！在很遥远很遥远，在大海的另一边，有一个将军大姐姐，和巫女大姐姐。
    </li>
    <li>
        <font style="color:#967c68;">旅行者 : 「有一个将军和一个巫女…」</font>
    </li>
</ul>

派蒙 : 啊——对了，巫女就是祭司，将军就是女王，这样说素达蓓应该比较好理解吧？

素达蓓 : 都是大姐姐吗？

派蒙 : 嗯，都是大姐姐！

_<font style="color:#967c68;">> </font><font style="color:#967c68;">「好久好久以前，在很远很远的王国里有一个又漂亮、又厉害的女王。但是，后来发生了战争，女王虽然赢了，但是失去了很多朋友。」<br/>「『呜呜，』她太伤心啦，说，『我要做一个机器人，帮我工作。然后，我要一辈子住在王宫里，再也不交朋友，这样就不会失去朋友。呜呜。』」<br/>「『哔哔，我知道了。开始工作。』机器人说，于是替女王治理王国。结果，有一些坏人开始蠢蠢欲动，要干坏事！」</font>_

素达蓓 : 等等，祭司大姐姐呢？

_<font style="color:#967c68;">> </font><font style="color:#967c68;">咳咳，话说回来，女王还有一个又漂亮，又厉害的祭司朋友，她不忍心看到朋友一直关在宫殿里。」<br/>「这时候，旅人来到了这个王国。旅人和旅人的同伴既聪明、又勇敢。」<br/>「祭司心想 : 『叮叮叮，这些旅人身手矫健、意志坚强。如果有他们的帮助的话…』」</font>_

_<font style="color:#967c68;">> </font><font style="color:#967c68;">以小孩子也不会失去兴趣的方式，讲述了女王与祭司（两人都是大姐姐）的故事。</font>_

派蒙 : …总之，到了最后，孤独的机器人还在努力工作就是了。但是，那就是另一个故事了。

素达蓓 : 大家都好厉害！那个旅人哥哥/姐姐虽然不是大姐姐，但也好厉害。素达蓓长大了也要变成这样的人。

派蒙 : 没问题的，一定能行！但是，如果不好好听话，在外面乱跑，走丢了的话，就不能变成厉害的大姐姐了哦。

（略）

派蒙 : 欸…是这样吗，真可惜。毕竟，拉娜姐姐说，她很想知道「兰那罗」是什么呢！

素达蓓 : 欸，拉娜姐姐也想知道吗？这样的话…

派蒙 : 嗯！而且，故事里的祭司大姐姐不是也说了吗 : 「叮叮叮，你不要像个闹脾气的小孩子一样不和人说话！」

旅行者 : 「叮叮叮！」

素达蓓 : 嗯…我知道了，祭司大姐姐和女王大姐姐的确是很好的朋友。

素达蓓 : 不过，不管怎么说，就像她们信任对方一样，我觉得，拉娜姐姐也会相信素达蓓，理解素达蓓不说的原因。

素达蓓 : 等素达蓓长大了，知道了很多事情，就告诉拉娜姐姐、告诉旅行者和派蒙。但是，现在不行。

(略)

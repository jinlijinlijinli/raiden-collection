## <font style="color:#967c68;">龙蛇洞宫试炼记</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">前往前方的遗迹处</font>**

渊上 : 白、白夜国因为其幽冥之特性…会、会出现过去残念的投影。

渊上 : 虽然他们的故事已经结束，但是他们那一刻的人格被保留了下来。甚至能面对你做出反应。

渊上 : 这种过于强烈的情绪，会被认为是「常世之罪」。

旅行者 : 「强烈的情绪」… / 「罪」…

渊上 : 因此这个奇特的地脉现象会被叫做「罪影」，或者「常世之灵」。

(略)

亚琉 : 您在蛇心之地看到那个祭坛的话，可得在附近好好找找提示了。有个地走官在那里设计了好半天。

派蒙 : 地走官？

渊上 : 特殊官员克托尼俄，指的是白夜国的武装幽冥判官。也就是「地走官」。

渊上 : 他们拥有特殊材质的令牌，可以让白夜国的魂灵显形。

派蒙 : 为什么听起来一点都不像是稻妻式的名字…

渊上 : 怎么说呢，海祇岛也是魔神战争期间内被造出来的。在那之前…

渊上 : 白夜国的历史可就充满了阿布拉克、斯巴达克、克托尼俄、吉干忒斯这种名字。

渊上 : 这就是天 之御史没怎么多加干涉的人文风貌吗…

派蒙 : 你在说什么？

渊上 : 啊啊，没什么。读书之人的坏习惯发作了。继续听阿尔戈斯说话吧。

亚琉 : 哦，对了，如今常夜到来，整个渊下宫都会对你展现出另一面。您在一路上应该会遇到不少残影。

亚琉 : 但是和我这种仪式留影不同。他们因为过于强烈的情绪而被渊下宫的常世法则选中，因罪而留影。

亚琉 : 它们即是地走官口中的「常世之灵」。但是因为「知罪则无罪」的法则，请不要直接告诉他们自己是残影。

亚琉 : 其他残影和我不同。一旦知道自己只不过是生前的影子，他们就会因此消散。

(略)

亚琉 : …还是回到试炼上来吧。我来为你打开最终试炼的通路。

亚琉 : 「于此罪海祇，有渎身名等四罪，复有欺生灵之八罪。」

亚琉 : 「于此镇常世之磐石，往罪不可追。」

派蒙 : 亚琉你在说什么？

亚琉 : 这是我的最后一项工作，诵读这段祝词。它意思就是，海祇大御神将要带着我们所有人的罪孽死去了。

亚琉 : 我还要最后委托您一件事。当你离开渊下宫之后，请不要说有关试炼的任何事。

亚琉 : 之前的历次试炼也是这么运作的，还希望您能遵守。

(略)

渊上 : 啊，对了，你们很好奇对吧？但我反而不知道从哪里开始解释了。

渊上 : 简而言之，渊下宫就是罪人的冥府黄泉嘛。而我就是犯了欺瞒与背叛之罪的人。

派蒙 : 我还是不明白…渊上你究竟想要做什么？

渊上 : 我是前来渊下宫寻找一本书的。那本书记载了白夜国在大日御舆建成之前的事情。

渊上 : 这段纪年，被白夜国民称呼为「日月之前的事」。那时大地甚至还没有神明行走其上，全大陆也都同属一个文明。

派蒙 : 太古存在这样的时代吗？「那时众神行走大地」已经是吟游诗人嘴巴里最久远的时间了。

渊上 : 啊，是啊。所以我也想找到这本书。这样我们深渊教团就有实证了。「众神」和天空岛果然是外来之物。

渊上 : 我唯一能知道的事情，就是大蛇因为不慎阅读了这本书，被天空岛宣判了死刑。

渊上 : 它甚至还筹划了举国搬迁、海渊封门和举国东征来掩盖这个真相。

渊上 : 为了海祇之民获得像人一样活着的权力，策划了一场宏大的献头之仪。

渊上 : 可是这本书啊，我在图书馆并没有找到，在大日御舆内也没有找到。

(略)

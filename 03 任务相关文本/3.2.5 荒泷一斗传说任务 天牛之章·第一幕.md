## <font style="color:#967c68;">鬼之恶</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">与稻妻的凯瑟琳交谈</font>**

派蒙 : 凯瑟琳，我们来了，有什么事找我们帮忙吗？

凯瑟琳 : 不好意思，又要麻烦你们了。这次是天领奉行直接交给冒险家协会的委托，很重要，也很危险。

凯瑟琳 : 协会在评估后认为，这份委托只能交给最资深的冒险家，于是我就想到了你们。

派蒙 : 嘿嘿，也没有那么厉害啦。

旅行者 : 听上去有点危险？ / 天领奉行自己解决不了吗？

凯瑟琳 : 先由我来说明一下吧。天领奉行近日下发了通缉令，他们想要找一个名叫「荒泷一斗」的鬼族青年。

派蒙 : 鬼族？我好像听说过，就是头上长角，看起来很凶的人吧。

凯瑟琳 : 是的，这个人很张扬很吵闹，所以在町街有点名气。但话虽如此，他以前也没有闯过什么大祸。

凯瑟琳 : 没想到，最近他竟然做起了抢劫和掳掠的勾当…

凯瑟琳 : 不只是做了坏事，在天领奉行众打算逮捕他的时候，他还袭击了执行抓捕的同心，带着身边的人逃走了。

<br/>

凯瑟琳 : 虽然协助天领奉行并非协会的本职工作，但既然是他们的委托，我们也同样会按规矩处理。

凯瑟琳 : 这件事就拜托你了，等待你的好消息。

<br/>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">打听荒泷一斗的消息</font>**

小仓澪 : 荒泷一斗？啊，他的事我知道，我一直觉得是天领奉行的人搞错了，他不可能为恶啦。

<br/>

上杉 : 至于心理上的动机，虽然现在有点难以启齿，在实施「眼狩令」的时候，他的神之眼被我们夺走了。

旅行者 : 原来是想报复天领奉行啊。

上杉 : 那个时候，荒泷一斗反抗得很厉害，我们费了非常大的力气，还求助了九条裟罗大人，这才成功。

上杉 : …这件事确实是我们的错，但没想到他为了报复，采取了如此过激的手段。

上杉 : 嗯，如果你们能制服荒泷一斗，就直接把他带到我这里来，我们会依规处置他的。

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">向珊瑚打听更多消息</font>**

派蒙 : 你好，我们想打听关于荒泷一斗的事。

珊瑚 : 又是他啊…当然没问题，之前我已经帮天领奉行做过一些调查了。不过更重要的，你们的咨询费带够了吗？

珊瑚 : 呵呵，听我说完嘛——这笔咨询费之前天领奉行已经付过了，所以你们只需要支付提成就行啦。

珊瑚 : 那么，要了解这件事的原委，就不得不提到，在稻妻很有名的童话故事——

_<font style="color:#967c68;">> </font><font style="color:#967c68;">在很久很久以前，有一对好朋友。他们一个是青鬼，一个是赤鬼。性格温柔的赤鬼总想和人类亲近，但人们害怕鬼，不想跟他做朋友。为了帮赤鬼实现愿望，青鬼就跑去人类村庄四处捣乱，再让赤鬼扮演「善良的鬼」将他赶走。果然，赤鬼因此被人类接纳，而为好朋友做完这一切的青鬼为了不成为累赘，收拾行囊默默离开了…</font>_

旁白 : 

很久很久以前在某个地方，有一个赤鬼和一个青鬼，他们是很好的朋友。

赤鬼长得像鬼，但和人一样温柔。青鬼长得像人，但和鬼一样孤僻。

赤鬼想和人做朋友，但人们都很害怕鬼，对他撒豆子，不愿意和赤鬼亲近。

于是青鬼向赤鬼出主意——

青鬼 : 

「阿赤，我去村子里捣乱，你来打败我」

「这样人们就会接受你了。」

旁白 : 

按照这个办法，赤鬼打跑了青鬼。赤鬼的善良与勇敢为人所知，人们终于接纳了赤鬼。

然而当赤鬼想要告诉青鬼这个好消息的时候，青鬼已然不知去向，只留下了一封信——

青鬼 : 

「我去旅行了。你再来找我的话，会被当成坏孩子的。」

「不用担心我，无论我去到什么地方」

「我们永远都是好朋友。」

派蒙 : 青鬼呢？青鬼后来怎么样了！

珊瑚 : 后来青鬼就消失了吧，再也没见过了，现在留下来的也只有赤鬼了。

派蒙 : 呜呜呜，怎么这样…青鬼真是个好孩子啊——

旅行者 : 童话故事和现实有关系吗？

珊瑚 : 当然，不然我也不会讲了。有一种说法是…这个童话就是由历史改编而来，而荒泷一斗就是故事里赤鬼的后代。

珊瑚 : 我想告诉你们的是，鬼族当年牺牲了很多，最后才能融入人类，但鬼族的性格里仍然有不安定的要素。

珊瑚 : 这种不安定是从血脉中传承下来的，荒泷一斗以前并没有做过什么坏事，但说不定有一天会性情大变呢？

派蒙 : 但这样的话，赤鬼不就背叛了青鬼的愿望嘛…

珊瑚 : 那都是很久远的事了。青鬼已经不知道多久没有出现过，估计早就消亡了，背叛自然也无从谈起。

珊瑚 : 而且…既然当事人都已经承认了，那还有什么可怀疑的呢？

珊瑚 : 根据我的调查，他一直朝着西南方向走，很有可能已经到了八酝岛。

珊瑚 : 天领奉行众没办法到珊瑚宫军的控制范围去抓人，所以荒泷一斗逃去那里也有足够的理由。

旅行者 : 我明白了，谢谢你的情报。

珊瑚 : 没关系，这是我应该做的。

派蒙 : 等等，我还有个问题，如果这个叫荒泷一斗的人性情大变，那是不是就会很凶恶，很暴躁？

珊瑚 : 应该是吧，从他之前和别人交手的情况看，他很擅长打架，有一股蛮力，光凭你们不知道能不能制服他。

派蒙 : 那…故事里面说对鬼族撒豆子的事，也是有用的吗？

珊瑚 : 哦，你这么一说我想起来了，荒泷一斗他好像对豆子过敏。

珊瑚 : 鬼族都有点害怕豆子，他尤其害怕，据说连碰一下都不行。

（略）

## <font style="color:#967c68;">鬼之义</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">向荒泷一斗了解鬼族的过去</font>**

荒泷一斗 : 本大爷坦率承认吧，天领奉行正在追查的抢劫与掳掠事件，都不是我做的。

荒泷一斗 : 我撒谎有我的理由，在解决重要的事情之前，我不想把无关的人卷进来。

荒泷一斗 : 我和你们的想法一样，都竭力想要避免争斗。无论我们谁受伤，都绝对不是好结果。

派蒙 : 那到底是什么事，不惜背负罪名也要去做呢？

荒泷一斗 : 唉…你们是外面来的对吧，那我还得从很久很久以前，赤鬼和青鬼的故事开始讲…

派蒙 : 等等，如果是童话故事的话，我们已经听过了。

荒泷一斗 : 什么嘛，你们已经知道了啊。那可就简单多了，省了我不少的麻烦。

派蒙 : 难道童话故事里发生的事情是真的吗？

荒泷一斗 : 关于鬼族的命运，童话里讲的都是真的——青鬼选择了自我流放，只有赤鬼留存了下来。

荒泷一斗 : 但其他的就和真正的历史没有什么关系了，童话讲述的都是美好故事，没办法提及残酷的真实。

荒泷一斗 : 很久以前的稻妻还很危险，那时候如果想要寻求雷电将军的庇护，就必须和人类搞好关系。

荒泷一斗 : 鬼族生来骄傲，要去「请求别人的接纳」并不容易。在这个过程中，鬼族慢慢分裂成了两派。

荒泷一斗 : 对人类的态度比较亲和的，就是赤鬼，而比较倔强和固执的，就是青鬼。

派蒙 : 我还以为是两个不同的种族呢，原来是一家人啊…

荒泷一斗 : 嗯，我们之间几乎没有区别，都是靠在角上涂不同的颜色，来区别立场。

旅行者 : 为什么青鬼必须牺牲？

荒泷一斗 : 因为在那个时候，人类对鬼族的戒心还很强。

荒泷一斗 : 赤鬼努力地想要找到和人类的和平相处之道，但青鬼时不时就会和人类产生矛盾。

荒泷一斗 : 人类可不管赤鬼青鬼什么的，只会认为鬼族不好相处。

荒泷一斗 : 一直这样下去，鬼族永远不会被人类接受。这个时候，赤鬼与青鬼里最德高望重的首领站了出来。

荒泷一斗 : 他们饮酒立誓，青鬼将会扮演恶鬼的角色，帮助赤鬼融入人类社会，但青鬼的首领也提出了两个条件。

派蒙 : 条件？

荒泷一斗 : 首先，鬼族不可对人类抱有成见，在被人类接纳之前要先在心中接纳人类。不可恃强凌弱，也不可自暴自弃。

荒泷一斗 : 第二，赤鬼要融入人类，但不可取悦人类。鬼族应该以正直的性格，奔腾的热血，强大的力量去赢得人类的尊重。

荒泷一斗 : 换句话说，就是在延续鬼族血脉的同时，守住我们的「骄傲」。

旅行者 : 原来是这样…

荒泷一斗 : 在那之后，因为决定自我牺牲，青鬼的族群越来越小，最后就消失了。

荒泷一斗 : 赤鬼和青鬼的故事，我从小听到大，我从来没想过，青鬼一族竟然活了下来…

派蒙 : 所以你的意思是，这些作恶事件都是青鬼一族的后人做的？

荒泷一斗 : 是的，很多人根本不在乎鬼角的颜色，甚至都不知道有青鬼的存在。

荒泷一斗 : 但「荒泷派」的弟兄们不会认错，他们亲眼在现场见到了角的颜色与我不同的鬼。

荒泷一斗 : 可如果是青鬼的后代，未免有些太奇怪了，本大爷实在是不能接受。

旅行者 : 因为青鬼很重视「骄傲」？

荒泷一斗 : 对啊！他们总是将「骄傲」看得比自己的生命更重！

荒泷一斗 : 我一直很钦佩选择了自我牺牲的青鬼一族，也明白我的祖先对鬼族的未来有怎样的期望。

荒泷一斗 : 抢劫，掳掠，哪里是鬼族的「骄傲」容许之事！

荒泷一斗 : 我觉得，那个青鬼一定是被骗了，或者被人威胁，才做了这样的事。可是，我没有证据…

旅行者 : 所以你是在争取时间？

荒泷一斗 : 是的，要是没有我混淆视听，那家伙肯定已经被天领奉行的人抓了。

派蒙 : 大辅不会也和这件事有关吧？他说你救了他，他应该知道你做的事。

荒泷一斗 : 因为他就是我在现场打跑了流浪武士，拼了命抢下来的。

荒泷一斗 : 那帮人洗劫他家的时候，他正好在外面玩，回来的时候，爸爸妈妈都已经被抓走了。

荒泷一斗 : 我要追查这件事，也是为了把他的父母找回来。

（略）

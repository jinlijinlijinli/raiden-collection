**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">前往鸣神大社向八重神子道歉</font>**

八重神子 : 哎呀小家伙，你怎么来了。嗯？还跟着一位稀客呢。

久岐忍 : 咳…宫司大人，我是来为荒泷派的事情道歉的。

久岐忍 : 我们会负起责任，清理掉所有的宣传单，并对神社的损失作相应的赔偿。

久岐忍 : 希望宫司大人，能原谅他们的无礼…

八重神子 : 啊，原来是为那件事…哎呀呀——这下可难办了。

八重神子 : 这里毕竟是鸣神大社，如此行径，往重了说，可是对将军不敬…

旅行者 : (一脸要使坏的表情…)

八重神子 : 要不这样吧？眼下我已派了一名巫女，去处理你们的小广告，所以神社里少了些人手。

八重神子 : 作为补偿，就由你来顶替这名巫女，在神社接待一日来客，如何？

久岐忍 : ——请容我拒绝。

八重神子 : 哦？拒绝得可真快，不过这样真的好吗？若是让天守阁听闻了此事…

久岐忍 : 唔，居然…

旅行者 : 千万不能被她带着走！

八重神子 : 哦？小家伙，你就这么不相信我？我好伤心啊——

旅行者 : 你一定在预谋什么不妙的事情吧！

八重神子 : 唉…真拿你们没办法——那你们就去给负责清理的巫女帮把手吧。

八重神子 : 之后就依你们说的，把小广告全部清理完就行。如何，够大度了吧？

旅行者 : 大度到不自然…

久岐忍 : 的确，完全不像是那个女人会干的…

久岐忍 : 不过清理小广告，本来就是荒泷派的责任。

久岐忍 : 况且就算有什么问题，也比当巫女要好多了…

久岐忍 : 旅行者，幸亏你陪我这一路了，接下来交给我一个人…

八重神子 : 商量好了？那可不许反悔了哦。

八重神子 : 我派去清理的巫女就在神社外，你出去不远就能看到，绝对不会认错。

八重神子 : 毕竟——就是你的姐姐阿幸嘛。

久岐忍 : ——姐姐！？

八重神子 : 就这样吧，小家伙，你们可要好好努力哦，呵呵…

久岐忍 : 哈…果然，还是被算计了。

稻城萤美 : 希望雷神大人保佑这位婆婆和她的孙女…

旅行者: 关于婆婆的眼睛…

稻城萤美 : 你们也注意到了吗？是啊，婆婆看东西不太清楚，每次上山来我们都有些担心。

稻城萤美 : 不过她总是不愿意多麻烦我们，说自己走了这么多年，一个人也能上下山…

稻城萤美 : 还好山道上也有神社的巫女，多少也能照看着些。

## <font style="color:#967c68;">活动简介</font>

「死兆星」号的首席技术官慕珍正在调查稻妻列岛的遗迹机械。调查各个异常区域，追踪奇特的雷元素活动现象，似乎就能探查遗迹机械的秘密…


## <font style="color:#967c68;">远航的准备</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与「南十字船队」的船员对话</font>**

慕珍 : 下一趟运单的雇主需要一批样品，就是产自此地的某种特殊遗迹机械的零件。

慕珍 : 根据雇主交给我们的目击记录分析，那些机械…或是生物，就藏匿在稻妻列岛，非常有趣。

旅行者 : 机械生物...?

慕珍 : …嗯，层岩巨渊的矿工以前也挖出过类似的东西，据说和五百年前的灾难有关。

慕珍 : 总之都是些…盘桓遗迹的不祥之物，令人生畏，却也令人兴奋…

## <font style="color:#967c68;">追随鸣雷的踪迹</font>

慕珍 : 旅行者，你回来了！

慕珍 : 你之前带回的那些晶片，我在船上研究了一番。看起来它们还很…「年轻」。

慕珍 : 这说明它们来自于新形成的元素结团…嗯，打个比方说，就像不久前才留在雪地上的、更深些的脚印。

慕珍 : 而现在呢，我希望你能帮我调查一下那些更「浅」的脚印…逆着它们的方向，往源头追查！

慕珍 : 所谓「更浅的脚印」呢，就是指那些已经凝结到一定程度，在地面附近沉积的雷元素聚合体。

慕珍 : 如果能够取得一定量的样本加以分类对比，或许能够画出大致的路线图…

派蒙 : 什么…深浅脚印、路线图的…没听懂呢…

旅行者 : 唔…确实难懂呢。

慕珍 : 哈哈，我打的比方可能有点不太贴切，不过你到了报告地点，自然就会知道了。

慕珍 : 好了，闲话不多说，快点出发吧！

## <font style="color:#967c68;">涉过未知的雷云</font>

> 	遗迹机械的定位工作几乎大功告成，但仍有一事困扰着慕珍…

慕珍 : 感谢你带回来的线索，现在我已经基本可以定位那些遗迹机械的所在了。

慕珍 : 不过，在此之前，我们还有一些小麻烦需要处理…

慕珍 : 附近分布的一些雷元素特异点仍然在干扰着精确定位，这些异常点的位置稍后我会告诉你…希望你能帮忙解决它们。

慕珍 : 这次还是一样，要辛苦你带回一些样本…我们收集这些东西首先自然是研究如何为我所用。

慕珍 : 其次…毕竟我们是商船队嘛，当然是好好研究一下商业价值啦！

旅行者 : 那你们现在成果如何？

慕珍 : 唔…你所交付的样品，善加利用的话，或许可以让「南十字」不再只依赖机动力，就能轻松躲避海上的雷暴。

慕珍 : 这样的话，来往稻妻的商路也会更加巩固，更能保障效率。

慕珍 : 不过…既然「锁国令」是将军的意志，或许我们这样做多少会让她老人家不悦吧…

慕珍 : 当然啦，最直接的研究成果，自然是通过雷元素异常增生物的「寿命」与「年龄」，估算出雷元素异常的范围与起始点。

慕珍 : 而起始点呢，就是我们的订单目标啦，神奇的古代机械生物！

## <font style="color:#967c68;">直面悠远的回响</font>

> 准备工作已经全部完成，只欠前去地下遗迹直面神秘的古代机械了…

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">前往遗迹地点-与慕珍对话</font>**

慕珍 : 哈哈，就是这里啦！

慕珍 : 原来在这里也有地下遗迹…唔。

旅行者 : 怎么了？ / 有什么发现吗？

慕珍 : 没、没什么。

派蒙 : 咦，是身体不舒服了吗？

慕珍 : 哈哈，我平时不怎么下船，看到遗迹入口这种大场面，还有点心虚罢了。

(略)

<br/>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">探索这座遗迹</font>**

慕珍 : 怎么，还需要点准备运动吗？

旅行者 : 关于遗迹... / 关于神秘的机械...

慕珍 : 毕竟我是航船技术官，陆地上的历史我了解的不太多，抱歉啦。

慕珍 : 不过这些遗迹，我想都与五百年前那场大灾难有关…

慕珍 : 我也是从小听老水手们提起过那场大灾，据说不论海陆都没有幸免深渊的侵袭…

慕珍 : 不过对我来说，和吓唬小孩的鬼故事差不多啦。

慕珍 : 毕竟亲眼所见的可怕，才是真的可怕！

## <font style="color:#967c68;">任务简介</font>

稻妻民间流传着一种这样的说法——运气好的话，你可以在昏昏欲睡时看到某种圆滚滚的可爱生物。这时，你最好放下手中的事情尽快进入梦乡，因为这种生物便是名为食梦貘的妖怪，她会趁你熟睡时一口吃掉你的噩梦。

不过，现在的稻妻人想要享受这种服务并不需要等待好运气的降临，他们只要前往稻妻城的秋沙钱汤预约心理诊疗即可。据说这里的心理诊疗师都是食梦貘化形而成的少女，许多被噩梦纠缠的顾客都在这里得到了解脱。

但是，原本生意兴隆的秋沙钱汤似乎正在遭遇一场严重的经营危机。而要了解个中原委，你先要经历一场梦中的邂逅…


## **<font style="color:#967c68;">梦中的邂逅</font>**

> 因为派蒙的心血来潮而重返稻妻的你偶遇了某种不知名的小妖怪，你被它吸引着，踏入了一场月下的邂逅…


**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">派蒙的心血来潮-前往稻妻</font>**

派蒙 : 嗯…我又想起了之前在这边追狸猫的日子，有些怀念呢。

派蒙 : 欸？那是什么？

旅行者 : 狸猫？ / 小猪仔？

派蒙 : 怎么看都不像吧？难道稻妻又有新的妖怪了？

派蒙 : 嗯…难道它想让我们跟过去？

(略)

梦见月瑞希 : 我是梦见月瑞希，叫我瑞希就好。我来自食梦貘一族，也是稻妻的妖怪之一哦。

派蒙 : 食梦貘？

小食梦貘 : 啾啾！

派蒙 : 是之前的那个小家伙…

梦见月瑞希 : 这就是我们一族原本的样子，两位刚刚应该就是被它吸引才误入了我的梦境吧？

梦见月瑞希 : 食梦貘拥有吞食人类噩梦的能力，而噩梦需要我们在自己的梦境里进行消化，你们刚刚看到的就是我消化噩梦的场景。

梦见月瑞希 : 我一口气吃了太多噩梦，它们堵在一起，让我有些消化不良…幸好它带你们闯了进来。

梦见月瑞希 : 也算是歪打正着，帮了我一个大忙，现在我可以好好消化这些噩梦了。

派蒙 : 我们就是发现你有些难受才凑过去的，虽然不知道具体发生了什么，但能帮到你就好。

派蒙 : 我最讨厌噩梦了，能吞食噩梦的妖怪，确实要好好帮助一下呢！

梦见月瑞希 : 不过，非常抱歉…

旅行者 : 怎么了？

梦见月瑞希 : 你在梦境里凑过来的时候，我从你身上分离出来的不是噩梦，而是美梦…

梦见月瑞希 : 之前吃了那么多噩梦，我的动作都变得机械了，没留意就一口咬了下去…

派蒙 : 原来食梦貘也可以吃美梦啊…话说回来，这是很过分的事吗？

梦见月瑞希 : 当然了，美梦对于人类来说十分珍贵，怎么能像噩梦那样随意吞食呢？

梦见月瑞希 : 我们食梦貘一族有个不成文的规定，未经允许绝对不能吞食他人的美梦，我真是太不小心了…

(略)



## **<font style="color:#967c68;">名为快乐的谎言</font>**

> 秋沙钱汤面临的经营危机似乎即将过去，但一场变故又突然来临。你和瑞希都意识到，你们并没有解决危机的根源…

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">前往鸣神大社寻找神子</font>**

派蒙 : 所以你还是想帮她的吧？

八重神子 : 我看得出来瑞希对秋沙钱汤这份产业的投入很大，现在秋沙钱汤遇到了困难，我作为朋友自然要关心一下。

派蒙 : 看你昨天的样子，我还以为你是去吵架的…

八重神子 : 瑞希应该和你们说过，我和她之间存在竞争关系吧？

八重神子 : 从同窗时期开始，她就一直这么认为。现在我是鸣神大社的宫司，她肯定也想通过秋沙钱汤证明自己。

八重神子 : 要是这种生死攸关的经营问题都必须靠我帮忙解决…我总该考虑一下老朋友的心情。

旅行者 : 难得见你这么体贴。

八重神子 : 就当你是在夸我吧。我这个老朋友习惯了体贴别人，也总该有人来体贴她一下。

(略)


## **<font style="color:#967c68;">梦魇的孑遗</font>**

> 在荒无人烟的孤岛上，你和瑞希找到了江村中弥的藏身地。有关近期这些噩梦事件的真相，似乎就潜藏其中…

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">深入秘境</font>**

久吕由命 : 哈哈哈…还是瞒不过你啊，吾等的天敌。

久吕由命 : 我为他织造的情绪茧房已经足够严密，却还是被你一步步拆解了，看来你早有准备。

梦见月瑞希 : 果然如此…

派蒙 : 这是什么东西？

梦见月瑞希 : 它是魇，很久之前在稻妻猖獗一时的妖怪。

梦见月瑞希 : 我们食梦貘吞食人类的噩梦，而魇则寄生在人类的噩梦里，所以我们彼此水火不容。

梦见月瑞希 : 之前听旅行者讲起那个奇怪的梦境，我就猜到了是魇作祟的可能性，并提前做了准备。

梦见月瑞希 : 不过即便如此，亲眼看到这种旧日的仇敌还是让我很意外，毕竟它们已经灭绝很久了…

久吕由命 : 那就正式自我介绍一下吧，在下久吕由命，魇之一族仅剩的孑遗。

梦见月瑞希 : 好久远的族氏…到底是怎么幸存下来的？

久吕由命 : 梦见月…这个族氏也让我想起了很久之前的时光。然而即便作为天敌，我对你也并未抱有多少恨意。

久吕由命 : 归根结底，还是因为人类作为宿主太过脆弱才导致了魇之一族的衰亡。

久吕由命 : 不过，我已经找到了复兴本族的方法，你来晚了！

江村中弥 : 呜啊！

梦见月瑞希 : 不好，我们得尽快追上他！

(略)



**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">调查魇的藏身地</font>**

派蒙 : 这里是…

旅行者 : 新的梦境吗？

梦见月瑞希 : 它竟然把我们拖到了边域…

派蒙 : 边域？

梦见月瑞希 : 简单来说，它算是「梦境中的梦境」，潜藏在稻妻人集体潜意识的深处，不需要梦主就可以独立存在。

梦见月瑞希 : 我能猜到，这只魇也正是藏在这里才没有和同族一起灭绝。

派蒙 : 瑞希，那只眼睛…

梦见月瑞希 : 它在尝试将这里改造成只适合它生存的噩梦环境，并大量制造自己的分身。

梦见月瑞希 : 这里连接着所有稻妻人的梦境，它可以将这里作为踏板，把自己的分身投放到每个稻妻人的噩梦里。

梦见月瑞希 : 一旦让它成功，它的族群确实就可以复活…

派蒙 : 那我们的目标就很明确了——打倒这个家伙！话说回来，用剑能干掉它吗？

梦见月瑞希 : 靠近些，或许就可以毁掉它的核心，但是…所有受害者的噩梦都被它聚集到这里了，它们都是魇的力量来源。

梦见月瑞希 : 这种数量，根本无法像处理江村中弥那样来解决问题，我们必须借助一些美梦的力量。

派蒙 : 美梦…去哪里找？

梦见月瑞希 : 边域里会有一些迷失的意识，它们当中肯定有脱胎自美梦的个体…跟我来！



## **<font style="color:#967c68;">后日谈</font>**

> 魇带来的危机终于被彻底解决，你也从瑞希那里收到了新的邀请函，派蒙终于可以享受她心心念念的全套服务了…

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">前往秋沙钱汤</font>**

八重神子 : 早啊，两个小家伙，昨晚的夜色还好吗？

旅行者 : 你偷看了？

八重神子 : 偷看？那棵树就在鸣神大社下面，难道要我把鸣神大社搬走吗？

梦见月瑞希 : 宫司大人来这里，所为何事？

八重神子 : 嗯…就当是随便逛逛吧，顺便带来一个天领奉行的消息。

八重神子 : 你的族人昨晚从水里捞上来的那个家伙已经脱离了生命危险，但心智似乎降低到了小孩子的水平。

梦见月瑞希 : 这样也好…另外，我先向宫司大人道谢了，昨天的事情能顺利解决，多亏了宫司大人的帮助。

(略)

八重神子 : 唉…还不如早点讲明呢，也不用让这小家伙两头跑了。

梦见月瑞希 : 旅行者的行动还是很有意义的，毕竟要为宫司大人考虑一下。

梦见月瑞希 : 那个「江村一玄斋」聚集了大批信徒，在他的底细被曝光之前，鸣神大社的宫司贸然介入进行打压的话…

梦见月瑞希 : 一帮吵吵闹闹的信徒会对鸣神大社的名誉带来多少影响，很难估量，所以宫司大人明面上最好没有过问此事。

(略)

八重神子 : 小家伙，有段时间没去神社求签了。

八重神子 : 哎呀，这不是小家伙吗？难道是打听到了我今天的行程，特意来这里见我？

旅行者 : 神子刚去见过将军吗？ / 我闻到了一股甜味…

八重神子 : 呵呵，鼻子还挺灵。不过是给某位不爱出门的友人带了些甜点，和时下最热门的轻小说罢了。

旅行者 : 影也开始追更了？

八重神子 : 她的说法是，想借此了解稻妻民众近来的娱乐生活和喜好变化。

八重神子 : 刚才，她还和我讨论了一番呢。一开始，她还只是一本正经地分析故事内容所体现出的读者偏好…

八重神子 : …可说着说着，就忽然很在意地问我：「所以，那个角色最后的结局究竟如何？」

八重神子 : 呵呵，看来就算是影，也难免会被精彩的故事所吸引呢。

旅行者 : 神子刚才的表情… / 非常值得被记录下来。

八重神子 : 哦？所以这才是你今天真正的来意吗？

八重神子 : 我知道了。一定是小家伙在旅途中时常会思念我，所以想要拍些画片留作念想，对吧？

八重神子 : 那就交给你了。可要用心挑选角度哦。

八重神子 : 呵呵，拍的不错，小家伙。

八重神子 : 如何？八重宫司大人的美貌，有好好地收录进你的镜头里吗？

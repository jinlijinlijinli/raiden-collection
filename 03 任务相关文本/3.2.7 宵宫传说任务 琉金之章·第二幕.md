## <font style="color:#967c68;">呼唤流星之人</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">离开教令院，与派蒙商量</font>**

_<font style="color:#967c68;">> </font><font style="color:#967c68;">在教令院你和派蒙得知流星雨只存在于传说里，想起平时宵宫的做事习惯，你们考虑再三，决定自创一个故事。</font>_

派蒙 : 所以我们现在要做的，就是让宵宫相信流星雨确实存在，然后付出一些努力吧？

旅行者 : 完成挑战，让收获水到渠成。

派蒙 : 如果我要去看一场流星雨，我最关心的事情是…

旅行者 : 流星雨出现的时间…以及最佳的观看地点。

派蒙 : 没错，就是这两个！名义上是寻找这两个信息，其实是带宵宫在须弥看风景和吃好吃的！

派蒙 : ——话虽这么说，这个「名义」不需要很严谨，但也不能一下子就被识破了。

派蒙 : 最好还能有童话故事中的那种又浪漫，又别出心裁的感觉…唔，好难。

旅行者 : 我想起了在「一心净土」…天上出现象征愿望的星星。

派蒙 : 哦，在大家口中也很流行「向流星许愿」这个说法！

派蒙 : 如果用「愿望」来编这个故事的话…

旅行者 : 流星雨是被愿望召唤而来的。

派蒙 : 哦，这样很有意思！那应该需要一个特定的许愿地点，不然满天就都是流星雨了。

旅行者 : 地点需要用某种东西去寻找。就像明论派需要观星设备。

派蒙 : 然后就以寻找或者制造设备的名义，到处玩，到处吃！

派蒙 : 嘿嘿，感觉是个完美的故事。

## <font style="color:#967c68;">丝织之愿</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">前往小仓屋-与神里绫华对话</font>**

神里绫华 : 嗯？这是…

派蒙 : 是祭典的广告。

派蒙 : 这么说来，我们来稻妻至今还没去过这种热闹好玩的场合呢！

旅行者 : 绫华是想去祭典吗？

神里绫华 : 不、不是这样的！咳咳…我是说，祭典什么的，在稻妻很是常见，我们社奉行早就习惯了这样的风俗哦。

神里绫华 : 每逢时节，稻妻的居民都会参加祭典，相对的，治安难度也会增加…

神里绫华 : 所以，祭典固然开心热闹，对我们来说却是一件值得操心的事。

(略)

小仓澪 : 您愿意来本店定制服装，我们小仓屋非常荣幸，不过…有件事比较棘手…

小仓澪 : 定做您想要的这件着物，需要用到霓裳花制成的丝绸。稻妻的丝绸大多是从璃月港进口的，但眼下…

小仓澪 : 唉，您也知道，稻妻正处于锁闭状态。

小仓澪 : 说实话，服装业受到了不小的影响，我们很难进到高档布料，成衣定制的业务也因此搁置了好一阵。

小仓澪 : 不过，要是客人能自备布料，我们就能帮忙做出衣服哦。

派蒙 : 意思是需要我们自己去买布？

神里绫华 : 连小仓屋都弄不到的高档布料…还有哪里能买到呢？

小仓澪 : 您可以到万国商会看看。他们的渠道比我们多些，毕竟都是来自全大陆各地的商贩。

小仓澪 : 就是价格可能有些贵，但在这样的非常时期，我想…能买到想要的东西就算不错了…

派蒙 : 原来在稻妻，定做衣服也变得这么麻烦了吗…

<br/>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">与久利须对话</font>**

久利须 : 前些年我们从璃月进了一大批丝绸，一直堆在仓库里。

久利须 : 最近听说，稻妻城内各个服装店积压的丝绸都卖得差不多了，我们正想着把这批货提出来卖个好价钱，谁知…

久利须 : 唉！那些浪人一截下我们的货，就立刻带着东西逃到树林里去了。我想报案，可是…

久利须 : 您也知道，我们这种外国商贩本就不受待见。「勘定奉行」的人一点儿都不想搭理我们，甚至巴不得我们倒霉呢…

神里绫华 : 虽然我个人也不怎么认可「勘定奉行」的行事作风，但久利须先生，这里毕竟是稻妻，请注意您的发言。

久利须 : 噢，抱歉，忍不住就抱怨了起来…

久利须 : 现在也没有更好的办法，单凭我们商会，怕是没法追回货物。

久利须 : 唉，或许这就是注定的破财之灾吧…

神里绫华 : 虽然不能走公务流程，但我可以帮您找回丢失的货物。

久利须 : 当然当然，您…哎？！

派蒙 : 哎？！

旅行者 : 这样真的没关系吗？

神里绫华 : 嗯。不过，虽然是以个人身份出面处理这次的事，但我的一言一行，多少都会关系到社奉行与神里家的形象。

神里绫华 : 我有一些顾虑，所以…希望您能为我保密。

(略)

久利须 : 可是，这样会不会给您个人带去麻烦？

久利须 : 万一勘定奉行的大人们对您有什么意见…您在民间声望很高，犯不着为了我们这种小人物蒙受损失啊！

神里绫华 : 您说笑了。

神里绫华 : 怎么说我也是神里家的大小姐。单凭勘定奉行的各位，应该还没有资格追究我的行为。

## <font style="color:#967c68;">他乡之食</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">与木南杏奈对话</font>**

派蒙 : 不过这么一说，那个名叫「椿」的人到底是谁呢？

神里绫华 : 关于这件事，我有一个初步推测。

旅行者 : 愿闻其详。

神里绫华 : 我认为，「椿」…或许是「狐狸神使」！

旅行者 : ……？

派蒙 : 「狐狸神使」？

神里绫华 : 嗯，我是这么想的。

神里绫华 : 就连我也从未听过母亲有这样一位朋友，如此神秘，一定是平日很难见到的高人吧。

神里绫华 : 稻妻自古就有不少关于狐狸神使的逸闻哦。

神里绫华 : 你们应该见过八重宫司了吧？她就是狐狸神使哦！

神里绫华 : 若是朝这个方向推测，稻妻大地上或许还有其他不为人知的狐狸神使…而那位「椿」，也许就是其中一员。

派蒙 : 哇哦，稻妻也有仙人啊？

## <font style="color:#967c68;">恒久之约</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">到山洞外查看笔记-与神里绫华对话</font>**

神里绫华 : 我想，我应当和你们分享这本笔记的真相。

神里绫华 : 虽然，里面的内容跟我想的完全不同就是了…

派蒙 : 不同？这不是狐狸神使的笔记吗？

神里绫华 : 不是狐狸神使。

神里绫华 : 「椿」的真身…

神里绫华 : 就是我的母亲。

派蒙 : 哎？！

神里绫华 : 很惊讶对吧？我、我也很惊讶…但这本笔记一开始便这样写了。

神里绫华 : 「椿与平时的我既相同又不同，作为椿时，我不是神里华代，而是一个最最平凡的女子。」

神里绫华 : 「以下所有，仅仅是一个普通的我所记录的生活琐事罢了。」

神里绫华 : 笔记中写的，大多是母亲平日里私密又琐碎的小心思…那些我们以为与「椿」有关的事，也是属于她的想法。

派蒙 : 意思是说，设计图纸跟异国料理…

神里绫华 : 嗯，都是我母亲想要尝试的东西。

神里绫华 : 或许对你们来说有些奇怪，但作为我而言，非常能够理解母亲的这种行为。

神里绫华 : 倒不如说，其实…其实我自己也有这样的一面…

神里绫华 : 看笔记的时候甚至有些不知所措，就好像是我的一些想法被人看穿了、写到笔记上一样…

派蒙 : 绫华…

神里绫华 : 母亲嫁给我父亲之后，就一直作为神里家的主母掌管各项事宜。社奉行身份相对尊贵，需要打点的方面非常多。

神里绫华 : 不仅如此，她的一举一动都代表着神里家族。人们总是注视着她，在这种情况下，她一定没有太多时间去做自己想做的事…

神里绫华 : 父母过世后，我和哥哥接手了神里家的一切。期间遇到的许多困难，可能对外人来说有些难以想象…

神里绫华 : 每当我遇到麻烦事，总是会想：母亲当年是否也这样做过？这样的事，她会怎么处理呢？

神里绫华 : 或许，真是太久没见她了吧。不知不觉中，就连我的记忆里也几乎只剩下母亲威严和高贵的一面。

旅行者 : ……

神里绫华 : 但…这是不对的。

神里绫华 : 当我看到这本笔记，就意识到了…她和我完全一样，无论我们背负着怎样的职责，也都只是一介普通人而已。

神里绫华 : 喜欢漂亮的着物，想要尝试每个地区的美食，渴望不曾见过的美景…

神里绫华 : 也许你们听见这样的话会笑话我不够成熟，但…我确实也有这样的想法。不是作为神里绫华，而是作为一个普通的女孩去生活。

神里绫华 : 母亲写到，她一直想参加稻妻本地的民间祭典。她说，天气晴朗的夜晚，自家中向远方眺望，偶尔能看见祭典的灯火。

神里绫华 : 我也看到过哦！非常热闹，人很多，灯笼里的火非常明亮，能照亮大片夜空…有时我们还要操心那里的治安问题呢。

神里绫华 : 只是，以我们的身份，贸然参加祭典或许并不合礼数。尤其在我父母的时代，社奉行与民众的关系还没有那么亲近…

神里绫华 : 就算没有人限制我们，社奉行的人突然出现在人群中，大家多少也会投来异样的眼光吧。会想着，我们去那里是要做什么呢？

神里绫华 : 母亲说，她不想让别人感到拘谨，希望大家尽情享受祭典的快乐与自由…她不愿打扰别人，也没有那么多闲暇，便一次都没有去过了。

派蒙 : 原来是这样…所以那张设计图纸上画的是她打算穿去祭典的衣服吗？

神里绫华 : 是的。祭典上有时会售卖异国料理，那些也是她想要尝试的东西。

神里绫华 : 说来有些冒昧，但…真没想到我的妈妈也有这么少女心的一面呢，哈哈哈。

派蒙 : 才不冒昧呢，我认为，你妈妈是个可爱又有责任心的人！

神里绫华 : ……

神里绫华 : 不知不觉中，我为母亲完成了一些愿望。唯独去祭典一事，我无法替她完成。

神里绫华 : 似乎…也没有机会见到她完成这件事了呢。

## <font style="color:#967c68;">愿与君同</font>

**<font style="color:#888888;">[任务]</font><font style="color:rgba(150,124,104,1);">与神里绫华一起进入祭典-与神里绫华对话</font>**

神里绫华 : 祭典还没有关闭，只是人不多了…我们得抓紧游玩。

派蒙 : 喂，你们看，那边摊子上有好多面具呀！

派蒙 : 听说参加祭典要戴面具，现在还有这种规矩吗？

神里绫华 : 以前会有这样的风俗哦，流传至今，就变成了一种流行的祭典装扮。不过，也不是绝对的。

三田 : 哟！这不是神里家的大小姐吗？

神里绫华 : 啊！我…咳咳，您好呀。

派蒙 : 旅行者，一路上真的好多人都认识绫华，果然是稻妻的名人呀…

三田 : 哈哈哈，当然啦！社奉行神里家是咱们稻妻非常有名望的家族哦。

三田 : 尤其是神里兄妹刚接手家业的时候，经常在外露面。

三田 : 有些年轻人出生得晚，无缘得见神里大小姐，像我这种活得比较久的大叔，还是在许多地方见过她的呢。

神里绫华 : 您过奖了，我和兄长大人也只是完成应尽的义务而已。

三田 : 哈哈哈哈，我还是头一回看到你家的人来祭典呢，是来执行公务吗？

(略)

三田 : 咱们这些平民百姓平时没少受社奉行关照，总得有个表示吧？你要是不拿，就是不给大叔面子哦。


<br/>

清水 : 嘿嘿，您可能不知道，我伯父先前受过社奉行关照，仔细想来，还是您父亲在时的事，由他亲自处理的。

旅行者 : 我的是「大吉·天」。

神里绫华 : 哇…你运气真好啊。

清水 : 客人恭喜啦，「大吉·天」，意为：云天有神威，风调雨顺，万事兴盛。您一定会继续交好运的哦！

<br/>

神里绫华 : 这里是买「绘马」的摊位。稻妻的人们会在名为「绘马」的五边形木板上画下或写下心愿，并祈求它能被实现。

派蒙 : 听起来跟璃月的海灯有点像，都是用来祈愿的道具。

(略)

派蒙 : 绫华这边画的…是天守阁吗？

神里绫华 : 是的，我的愿望是稻妻的大家平安幸福，家人朋友都能身体健康。

神里绫华 : 希望这个愿望能够实现…

旅行者 : 会实现的。

神里绫华 : 嗯，承你吉言。

神里绫华 : 呀，时间差不多了哦。

派蒙 : 啊…已经要走了吗？

神里绫华 : 是啊，祭典差不多要结束了。

神里绫华 : 越快乐，时光便流逝得越快…就像流水与落樱。

<br/>

吉川 : 我们摊位的绘马很灵验哦，各位的心愿一定会实现。

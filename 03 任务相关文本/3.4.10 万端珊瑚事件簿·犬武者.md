## <font style="color:#967c68;">活动简介</font>

稻妻似乎发生了一件奇案，于是万端珊瑚侦探社在冒险家协会发布了一个委托，若能协助破案的话，或许能得到丰厚的报酬…

## <font style="color:#967c68;">万端珊瑚事件簿·黑影之谜</font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">与龙二来到踏鞴砂对话后，去救小动物前，与龙二的额外对话</font>**

旅行者 : 关于「黑影」…

龙二 : 之前也听闻过，某个神秘组织会训练「忍犬」的传言。

龙二 : 据说，有一匹代号「戌壬」的忍犬，在暗中消灭了无数不利于稻妻的魔物…

龙二 : …当然只是传说而已。不过，这个「黑影」，或许就是传说中的忍犬也说不定…？

龙二 : …算了，总感觉像是在给自己找借口。

(略)

## <font style="color:#967c68;">万端珊瑚事件簿·它的认可  </font>

**<font style="color:#888888;">[任务]</font><font style="color:#967c68;">遇到了「黑影」，将旅行者和龙二一行人带至信处，读信</font>**

派蒙 : 呼——终于追上了。

龙二 : 嗯？它面前的是…一封信？

龙二 : 我们先看看吧，这是目前唯一的线索了。

派蒙 : 嗯！让我看看，里面写的是什么……

派蒙 : 「致有缘…」呃，太破了看不清楚。

龙二 : 可能是「致有缘之人」吧。

派蒙 : 哦哦，然后是…「我们家是专门训练忍犬的世家，为忍者们带来了许许多多可靠的伙伴。」

派蒙 : 「……此番征兵令下来，怕是凶多吉少。我此生没什么遗憾，唯一放心不下的只有影狼丸。」

派蒙 : 「小时候，它太弱了，所以忍者们来进行契约的时候，它被剩了下来。但是没关系，身为训练师，我不会放弃任何一只狗。」

派蒙 : 「经过日复一日的努力，影狼丸真的变得越来越厉害了。只可惜，它完全不想和任何忍者契约。」

派蒙 : 「虽然战争还未开始，但奉行所的催促越来越急，我已无暇顾及其他，现在到了不得不离开的时候了。」

派蒙 : 「只好留下这一封信，若是日后有人能找到这里，请代替我照顾一下影狼丸。」

派蒙 : 「它脸上有一道疤痕，是年幼时留下的，气场也与其他普通狗狗不同，很好辨认。」

龙二 : 信里说的这只影狼丸应该就是…

旅行者 : 带我们来的这只。

派蒙 : 确实很好辨认呢！信上还有行内容，我看看…

派蒙 : 「我知道这是不情之请，但也实在没有别的办法。还有，若是今后它愿意契约了，能带着自己中意的人来到这里的话，那么契约方法是…」

派蒙 : 哎呀，最重要的地方怎么划掉了！

(略)

稻妻的民俗学者宫岛，有些问题想考考你…

宫岛 : 这些可都是宝贵的文化，如果不传承下去的话…

旅行者 : 你在做什么？

宫岛 : 啊，我是宫岛，正在编纂稻妻民俗文化手册，人老了，希望还能做些有用的事情。

宫岛 : 看你的样子，不是本地人吧？

宫岛 : 你可能不知道，稻妻这个国家，也算是有着丰富悠久的历史与民俗。

宫岛 : 可惜现在的年轻人啊，生活在这里，却越来越不了解这片土地的故事了。

宫岛 : 居然还有些家伙，连雷神大人的正式尊名都不知道…

宫岛 : 真让人担心，再过几十年，等我们这些老家伙都过去了，稻妻会变成什么样…

旅行者 : 好像是「雷电将军」吧？

宫岛 : 果然，还是回答错了啊，「雷电将军」是一种别称。看来这种问题对异乡人来说还是太难了。

宫岛 : 不如让我考考你一些简单的。怎么样，有兴趣吗？

旅行者 : 有奖励吗？

宫岛 : 当然，好学的年轻人理应得到奖励。

宫岛 : 所以，如果准备好了就来找我吧。
